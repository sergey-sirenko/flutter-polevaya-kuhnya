# Материалы магазинов — FL-07-10

Статус на 28.09.2026: локальные материалы для просмотра владельцем. В магазины не загружались; PNG-иконки заменены в исходниках Android/iOS/Web, готовые сборки 0.1.0+4 ещё содержат прежние иконки. Новый выпуск требует отдельной пересборки и нового build number.

## Иконка

Обновление 01.10.2026, FL-BRAND-01: котелок с паром и огнём в зелёном круге по новому изображению пользователя. Текущий мастер — [прозрачный app-icon.png](../branding/app-icon.png), PNG RGBA 1024×1024. Шахматная подложка удалена локально через Sharp по разрешению пользователя; рисунок не перерисован. Прежний [app-icon.svg](../branding/app-icon.svg) сохранён как исторический исходник и генератором не используется. Баннер строится из [google-play-feature.svg](../branding/google-play-feature.svg) с текущим PNG вместо старого знака. Android/iOS-пакеты не пересобраны.

| Файл | Использование |
|---|---|
| icon-1024.png | Общий мастер, RGB без прозрачности; такой же знак в iOS asset catalog |
| google-play-icon-512.png | PNG RGBA 512×512, менее 1 МБ |
| rustore-icon-512.png | PNG RGB 512×512, сплошной фон, менее 3 МБ |
| google-play-feature-1024x500.png | Баннер Google Play 1024×500, RGB |

Иконка Web (192/512 any и maskable), favicon 32, Android legacy 48/72/96/144/192 и adaptive foreground, существующий iOS Contents.json сгенерированы одним [скриптом](../../tools/generate_brand_icons.cjs). Новые пакеты Flutter и генераторы Dart не добавлялись.

Повторное создание: `node tools/generate_brand_icons.cjs` из корня проекта, Node.js + пакет sharp. В локальном комплекте Codex задайте NODE_PATH в каталог node_modules из `load_workspace_dependencies`, затем используйте Node.js этого же комплекта. Скрипт перезаписывает только перечисленные ресурсы.

## Скриншоты

Уточнение FL-BRAND-01 от 01.10.2026: общая шапка Flutter использует отдельный ресурс [app-logo-cb1bbbb6c0df.png](../branding/app-logo-cb1bbbb6c0df.png), побайтно совпадающий с мастером app-icon.png. Хеш в имени меняет URL ресурса и исключает повторное использование прежней картинки по app-icon.png. При следующей замене мастера создать файл с новым хешем и обновить путь в pubspec.yaml и SiteBrand; генератор платформенных иконок продолжает читать мастер.

Получены непосредственно `adb shell screencap -p` с подписанного APK 0.1.0+4. PNG переведены в RGB без изменения пикселей/размеров; рамки, маркетинговые подписи и поддельные данные не добавлялись.

- `screenshots/android-phone/`: четыре кадра 1080×1920 — меню понедельника, регистрация, меню вторника, вход. Названия файлов задают порядок; при загрузке можно сначала поставить оба меню.
- `screenshots/android-tablet-preview/`: четыре кадра 1920×1080 — меню вторника, меню среды, вход, регистрация. **Это предварительная эмуляция большого окна на Pixel 6 AVD с wm size/density**, не приёмка на отдельном планшете. Перед загрузкой в планшетный раздел перепроверить на планшетном AVD/устройстве. На кадре среды есть штатная заглушка одной фотографии: для финальной рекламы лучше выбрать день со всеми изображениями.
- AVD `fl0302_storage_probe`, Android 15; phone wm 1080×1920 / 420dpi, tablet preview 1920×1080 / 240dpi. На завершении wm настройки сброшены и запущенный этой задачей эмулятор остановлен.
- Вход не выполнялся, поля пустые; корзина и заказы не заполнялись, регистрации/письма не отправлялись. Меню/фото — общедоступные рабочие файлы. Сетевой сбой при одной повторной загрузке сохранён только в build/fl-07-10, не в магазине; повторный запуск меню загрузил.
- iOS-скриншотов нет: тестирование отложено решением пользователя. Android/Web-картинки не заменяют снимки настоящего iOS-интерфейса.
- Хеши, размеры и объём файлов — [manifest.json](manifest.json).

## Требования магазинов

Проверено 28.09.2026; перед отправкой повторно сверить требования выбранного кабинета.

| Магазин | Форматы и ограничения |
|---|---|
| Google Play | Иконка 512×512 PNG с alpha, ≤1024 КБ; баннер 1024×500 JPEG/RGB PNG. Скриншоты JPEG/RGB PNG, минимум 2, стороны 320–3840, длинная ≤2 коротких. Для рекомендаций — 4 кадра минимум 1080, 9:16/16:9. |
| RuStore | Иконка 512×512 PNG/JPG ≤3 МБ, фон до краёв. Минимум 3 скриншота на выбранный тип устройства; телефон ≤3 МБ, планшет ≤5 МБ, максимум 2160×3840. Рекомендуется 16:9 (9:16 вертикально). |
| App Store | iOS-скриншоты отложены. Для 6.9″ официально перечислены, например, 1320×2868; размер должен соответствовать поддерживаемому устройству. Платформенные скриншоты получить после разрешения iOS-тестирования. |

Официальные источники: [Google Play](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en-GB), [RuStore](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication), [Apple screenshots](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/). Размер мастер-иконки 1024×1024 предусмотрен ТЗ §10.4 проекта.

Полная приёмка не завершена: знак ещё принимает владелец, новые иконки не проверены в установленных сборках, планшетные кадры предварительные, iOS отложена. Проверка меню/двух дат Android наблюдалась в этой задаче; полный сценарий заказа не проверялся. Самый быстрый следующий тест нового знака — пересобрать Web с новым build number и обновить flutter-test.obedmoscow.ru по SSH, затем Android отдельной подписанной пересборкой.
