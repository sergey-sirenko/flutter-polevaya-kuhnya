- [hero-wide.png](hero-wide.png): 1672×941, 2 586 088 байт, широкая композиция ≈16:9, использовать от 600 px.
- [hero-mobile.png](hero-mobile.png): 1448×1086, 2 513 603 байта, кадрирование исходника 4:3, использовать до 600 px. Генеративная правка, не побитовый crop.

- Текст/CTA только отдельными Flutter-виджетами, в изображениях текста нет.
- При подключении сохранять естественное соотношение сторон; весь основной продукт должен оставаться видимым. Не растягивать изображение.
- Общие ассеты для Web/Android/iOS. В FL-10-03 подключены только оптимизированные WebP-копии; PNG-мастера в пакет приложения не входят.

Спецификация: [city-lunch.md](../../../docs/design/city-lunch.md). PNG-мастера сохраняются; будущие оптимизированные копии не должны подменять источник без проверки качества.
