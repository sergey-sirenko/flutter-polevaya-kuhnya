## Где находятся методы, запросы, ответы и ошибки

База существующего HTTP-сервиса по изученным исходникам: `https://hleb-sol.su/Zakaz_http/hs/Obmen`. Полные шаблоны маршрутов, HTTP-методы, формы запросов/ответов и известные ошибки — в [инвентаре FL-00-05](tasks/FL-00-05.md). Полный список HTTP-сервиса шире списка методов сайта; автоматически включать дополнительные методы в Flutter не следует.

Для регистрации и смены email канонические поставляемые описания находятся в [Zak/docs/self-registration.md](../../Zak/docs/self-registration.md) и [Zak/docs/email-change.md](../../Zak/docs/email-change.md). При расхождении текста и кода сначала фиксируется вопрос владельцу API. Черновые карточки не вводят новые гарантии сервера.

## Примеры и доказательства

Формы JSON запросов/ответов и известные ошибки приведены в FL-00-05–07/11 и серверных документах по ссылкам выше. [Локальный набор ответов FL-01-14](test-responses.md) покрывает успех, пустые данные, старую/новую ошибку и целевой HTTP 401; рядом с каждой фикстурой указаны маршрут, статус и степень подтверждения. Это синтетические ответы для MockClient, а не утверждённый единый контракт или доказательство работы сервера. Перед бизнес-функцией примеры уточняются по её контрактной задаче.

Подтверждённые ранее ограниченные runtime-результаты находятся только в FL-00-14d: регистрация, парольный login, один существующий тестовый заказ в `user.order`, OPTIONS. Они не доказывают token refresh, расчёт суммы, отправку/повтор заказа, смену email, восстановление, удаление или browser CORS. Реальные реквизиты, коды, токены и содержимое профиля в примеры не включаются.
