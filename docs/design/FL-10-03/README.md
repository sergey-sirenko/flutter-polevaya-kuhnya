# FL-10-03 — локальные превью реализации

29.09.2026. [Телефон 390×844](home-mobile.png), [компьютер 1440×1000](home-desktop.png).

Снимки реальных Flutter-виджетов через RenderRepaintBoundary, с Arial и MaterialIcons. Это локальный widget-render, не браузерная или нативная приёмка. Категории в снимках заданы фикстурой с названиями из предоставленных материалов, фото не подгружались — показано состояние без фотографии. В приложении категории и фотографии по-прежнему поступают через существующий router/provider меню с photo_version. Приёмочные данные или заказы не создавались.

Изображения показывают видимую область; остальная страница прокручивается. Hero — подготовленные в FL-10-01 изображения, оптимизированные без нового кадрирования. Макеты варианта 03 остаются источником направления, эти PNG показывают текущую реализацию.
