# FL-10-04 — локальные превью каталога

[Телефон 390×844](menu-mobile.png) · [Компьютер 1440×1000](menu-desktop.png).

Снимки Flutter-виджетов с Arial и MaterialIcons, 29.09.2026. Синтетическое меню на 02.01.2030 с шестью блюдами; источник — локальная фикстура, сетевые фото не запрашивались. Показаны штатные заглушки фото и пустая корзина, данные заказов не создавались. Небольшая диагональная метка справа сверху относится к локальному debug-режиму.

Это проверка реализации в widget-render, не браузерная/нативная приёмка. В приложении реальные фото, названия, даты, цены и ограничения поступают из существующих providers; photo_version сохраняется. Полоса общего итога и новая корзина — следующая FL-10-05.
