# Описания магазинов — FL-07-11

Статус: подготовлено для просмотра владельцем, в кабинеты не внесено. Канонические поля — [ru-RU.json](ru-RU.json). Это один комплект русских текстов для Google Play, RuStore и будущего App Store. Название согласовано ранее, новые описания и контакты ещё требуют приёмки владельцем.

| Полное описание | fullDescription | fullDescription | fullDescription |
| Ключевые слова | Отдельного поля здесь не заполняем | Отдельного поля здесь не заполняем | appleKeywords |

| Политика | privacy.url после закрытия открытого пункта | То же | То же |

Латинское `Polevaya kuhnya` — ранее принятое написание названия для мест, где требуется латиница, не готовая английская локализация. Поля категорий, возрастного рейтинга, Data Safety/App Privacy и удаления аккаунта не заменяются рекламным описанием: это FL-07-12 и задачи публикации.

## Короткие тексты

Название: **Полевая кухня**.

Google Play / RuStore: **Меню на неделю и заказ обедов в офис для клиентов «Полевой кухни».**

App Store subtitle: **Обеды в офис по меню**.

App Store keywords: `обеды,доставка,офис,меню,заказ,Москва`.

Полное описание хранится только в fullDescription JSON: скопируйте значение как обычный текст с настоящими переносами строк. Пункты списка — часть описания, разметка HTML не используется. Код клиента, регион и зависимость от интернета объяснены прямо; сроки/цены не зафиксированы рекламным обещанием.

## Лимиты и источники

Проверено 28.09.2026; перед внесением в кабинет повторно сверить действующие ограничения.

- [Google Play — создание карточки](https://support.google.com/googleplay/android-developer/answer/9859152?hl=en): name ≤30, shortDescription ≤80, fullDescription ≤4000 символов.
- [RuStore — публикация](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication): название ≤30, краткое ≤80, полное ≤4000; краткость начала полного текста учитывает сворачивание после 2000.
- [Apple — App information](https://developer.apple.com/help/app-store-connect/reference/app-information/app-information/): название 2–30, subtitle ≤30; Privacy Policy URL обязателен для iOS.
- [Apple — Platform version information](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/): description ≤4000, plain text; keywords **до 100 байт**. Русский keyword-список проверен в UTF-8, не только по символам. Support URL должен давать реальные контактные данные.

Количество символов/UTF-8 байт текущих полей — [validation.json](validation.json). Это локальная проверка документа, не автоматическая приёмка магазином.

Пересборка/выкладка пропущена по указанию пользователя от 28.09.2026. Эта задача меняет только документы; Web/Android +4 и новая иконка только в исходниках остаются прежним состоянием. После будущих изменений приложения быстрый пользовательский тест — пересборка Web и SSH-обновление flutter-test; сейчас повторная публикация для текстов не нужна.
