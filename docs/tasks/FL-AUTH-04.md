# FL-AUTH-04 — Причины отказа регистрации

## Требование

01.10.2026 пользователь поручил показывать причины отказа регистрации. Основание: живая диагностика FL-AUTH-03 обнаружила `ambiguous_employee` из-за нескольких сотрудников одной организации с одинаковой почтой; приложение заменяло его общим сообщением о недоступности регистрации устройства.

## Реализация

- `RegistrationController` различает дубли почты и несколько сотрудников у устройства; отдельно объясняет несовпадение устройства, запреты организации/устройства/сотрудника, недоступность профиля, изменение привязки и занятую почту.
- Для кодов с несколькими причинами используются известные сообщения действующего контракта Zak. Неизвестные сообщения не выводятся напрямую: остаётся безопасный общий текст. Изменение не требует загрузки нового серверного модуля и не снимает запреты доступа.
- После `access_denied`, `ambiguous_employee`, `device_mismatch`, `email_in_use` при подтверждении или повторной отправке форма очищает временный контекст и возвращает к реквизитам с причиной отказа. Повторное введение кода и повторная отправка для прежнего контекста больше не предлагаются. Неверный код допускает исправление; сетевые ошибки и ограничение частоты сохраняют прежний сценарий.
- Все изменения в общем коде Flutter Web/Android/iOS. Версия 0.1.0+44; минимум +1 и пустые значения выпусков Android/iOS сохранены. Публичная версия при начале +43.

Полные тесты: 653 прошли. Diff-check изменённых файлов: без замечаний.
