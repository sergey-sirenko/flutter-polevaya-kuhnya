# FL-02-11 — Обеспечить профиль по токену

## Назначение

- Бизнес-цель: без пароля получить условия клиента, профиль и историю (`user.order`); неверный токен и отказ доступа различимы по контракту.
- Требования: API-4, NFR-SEC-2, FR-P1; C-08 (серверная привязка).
- Модуль: Zak `ОбменHTTP.ШаблонUserLogin`; Flutter `core/auth` (разбор профиля); [docs/profile-by-token.md](../profile-by-token.md).
- Ответственный: агент.

## Входные условия

- Клиентская модель сессии — FL-01-13; аудит — FL-00-06.
- Runtime API / загрузка базы 1С не выполнялись.

## Оценка перед выполнением

- Объём: вся доступная часть без живой приёмки.
- Сложность: 7/10; трудоёмкость высокая, ≈10% этапа 2; LLM средняя.

- [x] Статически сверить token-ветку `User/login` в Zak.

## Критерии завершения

Условия/профиль/`order` доступны по `{token,deviceId}` без пароля (код + контракт). Неверный токен и отказ доступа описаны. Живая приёмка — отдельно.
