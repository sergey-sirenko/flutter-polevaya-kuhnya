# FL-UX-49 — Восстановление корзины без закрытых дней

## Назначение
По поручению 11.10.2026 автоматически сбрасывать локальный набор закрытых дней и загружать только доступные дни обычной корзины. Общий код Web/Android/iOS; ответственный Codex.

## Входные условия
API snapshot v1 возвращает профиль, allowedDates и revisions в одном согласованном ответе. Серверные заказы не отменяются. Ошибки сети/владельца/конфликты открытых дней не являются основанием сброса. Исходная локальная сборка +88; накопленные изменения FL-UX-48 сохранить.

## Оценка перед выполнением
Вся задача: сложность 4/10, трудоёмкость низкая, LLM средняя. Отдельная задача без определённого этапа, доля не рассчитывается. Основание: многодневный набор, постоянное хранение, выбор даты и защита асинхронного восстановления.

## План и критерии завершения
- Исключить закрытые/отсутствующие в меню даты при подготовке и восстановлении обычного набора.
- Сохранить правки доступных дат, выбрать доступную дату вместо закрытой; при пустом наборе очистить сохранение.
- Проверить целевыми тестами, analyze и test Web build; поднять версию до +89.

## Результат 11.10.2026
Реализация завершена в CartEditController._prepare. При подготовке/восстановлении обычной корзины даты вне актуального меню, вне разрешённых дат либо с changes=false не включаются в membership/originals/names/quantities; их legacy draft удаляется. Выбранная закрытая дата заменяется первой доступной. Если дат нет, сохранённый набор очищается и активная корзина не создаётся. Отфильтрованный снимок записывается до применения в памяти, поэтому после F5 закрытые даты не возвращаются. Пользовательские количества открытых дат сохраняются, включая намеченные отмены. Серверные заказы не отменяются и basket не вызывается восстановлением.

Ошибки сети/владельца, конфликт revisions и некорректный состав доступного заказа продолжают сохранять набор и блокировать применение. Pending/unknown, W07 и проверки epoch/generation/API сохранены. Пустой menudates по действующему контракту означает отсутствие ограничений. Отдельный режим повтора заказа не изменён. Уточнён канонический docs/cart-multiday.md v1.3; подпись FL-UX-48 сохранена.
