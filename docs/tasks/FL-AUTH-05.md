# FL-AUTH-05 — восстановление реквизитов входа

[Единая карточка](../../../docs/tasks/FL-AUTH-05.md), [канонический контракт Zak v1.0](../../../Zak/docs/password-recovery.md).

Локальная Web 0.1.0+46. Страница «Не помню пароль» принимает почту и явно запрашивает письмо с кодом входа и текущим паролем. Поиск в 1С в трёх справочниках в заданном порядке; первое совпадение по коду и ссылке. Пароль остаётся прежним, секреты не возвращаются в приложение, ошибки показываются собственными текстами. Блокировки доступа сохраняются. Письма поступают в штатную очередь ЭлПисьма, повтор ограничен минутой.

Analyze чистый, 15 тестов формы и 664 полных теста прошли, release Web +46 собран с действующими API/data. BSL статически проверен; в ИБ не загружен. Метаданные не менялись. Android не пересобран, iOS не запускалась; живых писем/заказов/коммита/публикации нет.

Далее пользователь загружает два модуля, затем «Пересобрать Web и обновить тестовый flutter-test.obedmoscow.ru по SSH»: сборка готова, `pwsh -File .\tools\deploy_web_test.ps1 -SkipBuild`. Точный состав и сценарии приёмки — в единой карточке. Следующая приёмка: сложность 3/10, трудоёмкость низкая, ≈15% пакета, LLM средняя. Остановка по AGENTS.md.
