# FL-UX-35 — Действия сохранённого набора в одной строке

## Назначение
По поручению пользователя расположить «Продолжить набор» и «Начать заново» рядом в одной строке. Сохранить красный цвет, действия и блокировки.

## Входные условия и оценка
Общий CartWorkBanner для Web/Android/iOS. Вся подзадача: сложность 1/10, трудоёмкость низкая, LLM лёгкая; типовая правка раскладки. Отдельный UX-пакет вне этапа, доля старого этапа не назначается. Тесты/превью не запускать по сохранённому ограничению пользователя; живая приёмка Web после выкладки пользователем.

## План и критерии
- Перенести две существующие кнопки в Row с ограничением ширины и масштабированием текста.
- Сохранить условия показа каждой кнопки и обработчики.
- Поднять сборку на один; analyze, diff-check, version-policy, локальная тестовая Web-сборка.
- Обновить PROJECT_STATE и остановиться перед живой приёмкой.
