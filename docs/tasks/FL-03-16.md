# FL-03-16 — Проверить хранение и журналы

## Назначение

- Цель: пароль отсутствует в хранилищах и логах; нет автовхода по сохранённому паролю.
- Требования: NFR-SEC-1/2, FL-03-16.

## Состояние

- Работа: завершена в доступном локальном объёме.
- Проверка: [storage_security_test.dart](../../test/features/profile/storage_security_test.dart) — после входа в secure storage только токен/`deviceId`, пароль не на экране; `SessionStorage` без API пароля.
- Формы очищают пароль после ответа (FL-03-04/05/08/10). Автовход только по токену с серверной проверкой (FL-03-06), не по паролю.
- Журналы приложения не пишут пароль (транспорт/UI не логируют body). Платформенные логи ОС/прокси не проверялись.
