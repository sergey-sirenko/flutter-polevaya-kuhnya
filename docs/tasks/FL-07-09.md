# FL-07-09 — Подготовить демо

## Назначение

- Бизнес-цель: дать проверяющим магазинов рабочую тестовую учётную запись и понятный сценарий без персональных данных обычных клиентов.
- Требования ТЗ: API-11, ST-iOS-4, §10.4.
- Модуль: инструкция проверяющего и уже существующие экраны входа, заказов и профиля.
- Ответственный: владелец ИБ хранит реквизиты и перед выдачей сверяет состав профиля; агент описывает путь по сборке без секретов.

- Окружение: рабочая ИБ через существующий API.
