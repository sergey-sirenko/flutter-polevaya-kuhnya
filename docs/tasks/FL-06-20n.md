## Что сделано

- Сверены FR-P3 и фактические встроенные метаданные версии; выявлено, что старый helper сравнивает сначала build и не годится для предлагаемого сравнения кортежа version/build.
- Подготовлен один канонический проект: общий источник version.json Flutter-домена своей среды, вложенный policy schema 1, единый minimum, реальные releases каналов, строгие ошибки/сравнение и сохранность. Предлагаемый test-минимум 0.1.0+1 не принят и не опубликован.
- Указаны legacy JSON, unknown без ложной несовместимости, сохранение уже известного required при сбое повтора, явное действие пользователя, ожидание записи draft/pending и отсутствие автоматического POST/reload.
- В текущем Web +8 обнаружен служебный worker с unregister/client.navigate при активации; это риск неконтролируемой навигации, не доказательство PWA-кэша. Контракт требует отдельной проверки/доработки Web-кэша/bootstrap/worker до приёмки безопасного обновления. Статический просмотр не доказывает фактические события браузера.
- ARCHITECTURE содержит проект ADR-9, не принятое исключение П3. Матрица FR-P3 и описание окружений ссылаются на канонический контракт; новый APP_VERSION_URL ещё не поддержан кодом/скриптами. Расширение JSON потребует адаптации существующих точных проверок build/deploy/rollback, проверки не отключаются.
- Android/iOS/Web: предложены общий минимум и состояния, разные действия распространения в core/platform. Код/настройки не изменены; сборки/публикации/запуски отсутствуют, iOS не тестировалась. Web +8, локальные APK/AAB +4 прежние. Zak/Caddy/старый сайт не менялись.
