# FL-02-17b — Привести ошибки Zak к контракту

## Назначение

- Бизнес-цель: серверные HTTP-ответы различают истечение сессии, отказ устройства и бизнес-отказ по [api-errors.md](../../../Zak/docs/api-errors.md) v1.0.
- Требования ТЗ: API-9, NFR-SEC-4; §5.2 дорожной карты.
- Модуль: Zak `ОбменHTTP`, `HTTPServices/Obmen`, `ДоступСотрудниковКлиентов`.
- Ответственный: агент.

## Входные условия

- Зависимые задачи: FL-02-17a (контракт v1.0).
- Окружение: исходная выгрузка Zak; без запуска 1С/ИБ.
- Ограничения: только BSL. Не вызывать HTTP, не загружать ИБ, не менять Flutter-код (FL-02-17c).

## Оценка перед выполнением

- Оцениваемый объём: вся подзадача b.
- Сложность: 7/10.
- Трудоёмкость: средняя; ≈2% этапа 2.
- Рекомендуемая категория LLM: сложная.

## План

- [x] Хелпер HTTP-статуса; кодированный `ОтветОшибка`; авто-статус корзины и регистрации.
- [x] Login / menudates / basket: 401/403/коды; без утечки исключений.
- [x] Корзина `invalid_session`; email-сессия; безопасный 500.
- [x] Документы, карточка, PROJECT_STATE; остановка.

## Критерии завершения

В исходниках Zak отказы сессии — HTTP 401 с кодом, устройство/доступ — 403, бизнес — 400 (409 для закрытого дня), публичный 500 без текста исключения. Поле `error` сохранено. Платформа не запускалась.

## Что сделано

В [ОбменHTTP](../../../Zak/Konf/CommonModules/ОбменHTTP/Ext/Module.bsl):

- `КодСостоянияПоКодуОшибки` (401/403/409/500 по `code`);
- `ОтветОшибка(Текст, Код, Статус)` с полями `code`/`message` при непустом коде;
- `ОтветОшибкаКорзины` выбирает статус по коду; корзина отдаёт `invalid_session` вместо `invalid_token`;
- `User/login`, `Orders/menudates`, старый `Orders/basket` кодированы; JSON-исключения не утекают.

В [ДоступСотрудниковКлиентов](../../../Zak/Konf/DataProcessors/ДоступСотрудниковКлиентов/Ext/ObjectModule.bsl): `ОтветРегистрации` ставит HTTP по коду; истёкший токен смены email → `invalid_session`.

В [Obmen](../../../Zak/Konf/HTTPServices/Obmen/Ext/Module.bsl): `ОтветОшибкаСервера` — фиксированный текст без `ОписаниеОшибки()`.

Обновлены `api-errors.md`, `device-disconnect.md`, `email-change.md`, `safe-order-retry.md`, `profile-by-token.md`.
