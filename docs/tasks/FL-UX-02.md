# FL-UX-02 — Читаемость двух колонок календаря

## Назначение

Первый шаг принятого пользователем плана по FL-UX-01: убрать разрывы слов рядом с кнопкой дня. Две колонки недель, одинаковая высота карточек и бизнес-правила сохраняются. Общий UI Web/Android/iOS, API и Zak не затрагиваются.

## Входные условия

Web +34 публичный и локальный; HEAD 7a375d161d31e1eb84087f0025c767e25252af1e, master с накопленными изменениями. Основа: FL-10-19, docs/design/city-lunch.md, замечание P1 календаря в docs/testing/FL-UX-01/README.md. Пользователь поручил реализацию плана; 01.10.2026 указанием «доделай план» разрешил завершить локальный пакет подряд. Выкладка остаётся пользовательской. iOS runtime запрещён, SSH-выкладку выполняет пользователь.

## Оценка перед выполнением

Вся подзадача: сложность 4/10, трудоёмкость средняя, LLM средняя. Отдельный UX-пакет вне прежней оценки этапа 10; доля этапа не назначена. Расчёт геометрии, скидки, разные состояния даты и реальные метрики шрифта; внешняя Web-приёмка отдельно.

## План и критерии завершения

- [x] Определять минимальную ширину текста по словам статуса и сумме с текущим шрифтом/масштабом.
- [x] Переносить кнопку вниз при нехватке ширины; не занимать её место в закрытых днях.
- [x] Проверить 320/360/390/430 px, масштабы 1 и 1,6 реальным шрифтом, одинаковую высоту и действие.
- [x] Analyze, общий набор и диагностический UX-набор, diff-check.
- [x] Шаг кода +35; включён в итоговую локальную Web-сборку +37, документация обновлена.
