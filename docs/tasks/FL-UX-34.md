# FL-UX-34 — Красный текст блока сохранённого набора

## Назначение
По снимку пользователя убрать фразу «Перед продолжением проверим заказы в 1С.» и сделать красными сообщение и кнопки «Продолжить набор»/«Начать заново» в выделенном блоке.

## Входные условия и оценка
Общий CartWorkBanner Web/Android/iOS. Вся подзадача: сложность 1/10, трудоёмкость низкая, LLM лёгкая; типовая правка текста/стилей. Отдельный UX-пакет вне этапа, доля старого этапа не назначается. Проверка заказов и действия сохраняются. Тесты/превью не запускать по сохранённому ограничению пользователя; визуальную приёмку Web выполняет пользователь после выкладки.

## План и критерии
- Сообщение: «Есть сохранённый набор.» красным цветом AppTheme.danger.
- Две кнопки выделенного блока красные, обработчики и блокировки сохранены.
- Поднять номер на один, проверить анализатор, diff и version-policy, собрать тестовый Web.
- Обновить PROJECT_STATE, остановиться перед выкладкой/живой приёмкой.
