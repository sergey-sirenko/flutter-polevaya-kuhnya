# FL-03-06 — Восстанавливать сессию при старте

## Назначение

- Бизнес-цель: открыть личный раздел только после серверной проверки сохранённого токена и получить свежий профиль без пароля.
- Требования: NFR-SEC-1–4, FL-03-06 дорожной карты.
- Модуль: Flutter `core/auth`, router.

## Входные условия

- Зависимости: инфраструктура FL-01-13, контракт профиля FL-02-11, хранение FL-03-02/03.
- Контракт: [профиль по токену 1.0](../profile-by-token.md), `POST V1/User/login` с `token`/`deviceId`; пароль не передаётся. Недействительная сессия очищается; связь/неоднозначный отказ оставляют токен для повтора.
- Окружение: локальные Web и Android; iOS-тестирование отложено пользователем.
- Ограничения: тестовые токены синтетические; реальные учётные данные и заказы не создаются. Сервер Zak не изменяется.

## Оценка перед выполнением

- Оценивается вся FL-03-06.
- Сложность: 6/10.
- Трудоёмкость: средняя, ≈6% этапа 3.
- LLM: средняя.
- Основание: есть каркас восстановления, требуется проверить интеграцию старта, состояния маршрута и свежесть профиля; живая проверка зависит от доступного тестового токена.

## Критерии завершения

Сохранённый токен не открывает личные данные до проверки `User/login`. Успех обновляет профиль в памяти без пароля. Отказ авторизации очищает токен и профиль; сбой связи оставляет токен, но закрывает личные данные и допускает повтор.

## Состояние

- Работа: завершена в доступном локальном объёме.
- Реализация: существующий стартовый путь через `SessionRepository.verify` подтверждён; добавлен `sessionProfileProvider`, возвращающий профиль только для подтверждённой сессии.
- Проверка: 172 теста и analyze прошли; Web и Android debug APK собраны. Живая проверка восстановления на устройствах с действующим тестовым токеном не выполнена.
