# FL-09-16 — Портрет установленного приложения

## Назначение

- Бизнес-цель: основной сценарий установленного Android и iOS остаётся портретным.
- Требования ТЗ: П3, П5, NFR-PWA-1, [ADR-10](../../ARCHITECTURE.md#adr-10--портрет-установленного-android-и-ios).
- Модуль: платформа и оболочки Android, iOS и Web.
- Ответственный: общий код и согласованные настройки платформ.

## Входные условия

- Зависимые задачи: этап 9. Владелец 28.09.2026 подтвердил портрет для Android и iOS и отказ от блокировки Web.
- Нужные контракты и решения: ADR-10. Поворот всей страницы через CSS не переносится.
- Окружение: локальный тест правила и анализ.
- Ограничения выполнения и проверок: iOS не запускать; Android APK/AAB не пересобирать; публикация отдельно.

## Критерии завершения

Установленные Android и iOS поддерживают только портрет. Web, включая установленную PWA, ориентацию не блокирует. Страница целиком не поворачивается. Исключение записано в ADR-10.

## Что сделано

Android-манифест и оба списка iOS оставляют только портрет. Тот же список задаёт `distribution.dart` при запуске установленного Android и iOS. На Web `SystemChrome` не вызывается. Из `web/manifest.json` убран `orientation`, чтобы браузер и установленная PWA не получали запрос портрета. Поворота страницы нет.
