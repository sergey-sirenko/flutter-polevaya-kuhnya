3. Проверить Назад и перезагрузку с черновиком до отправки; не терять pending.
4. Отправить один раз; сверить квитанцию и серверную историю. При неизвестном результате использовать проверку результата вместо второго заказа.

6. Отменить только созданный тестовый заказ; подтвердить результат и отсутствие активного состава в истории/календаре.
