# FL-02-10 — Подготовить набор сверки

## Назначение

- Бизнес-цель: ≥10 корзин с ожидаемыми результатами для сверки клиента и (позже) сервера — BL-5.
- Требования: BL-5, FR-C2; [pricing-spec](../pricing-spec.md) v1.0.
- Модуль: `docs/pricing-reconciliation.md`, `test/fixtures/pricing/`, автотест набора.
- Ответственный: агент (формат + синтетика); заказчик (реальные обезличенные данные).

## Входные условия

- FL-02-07…09 завершены.
- Решение 26.09.2026: тестовые пользователи рабочей базы; без отдельного API 1С.
- Runtime / захват реальных корзин **не разрешён** в этой сессии и данных не предоставлено.

- Объём: доступная часть без runtime.
- Сложность: 6/10; трудоёмкость средняя, ≈7% этапа 2; LLM средняя.
- Внешнее ожидание: обезличенные реальные корзины / тестовые учётки.
