# FL-UX-30 — Компактные карточки дней и состав заказа

## Назначение и входные условия

Поручение 02.10.2026 по двум снимкам: карточка дня в две строки, дата «Вт 06.10», корзина сверху, суммы рядом; в составе заказа убрать статус и показать суммы рядом. Общий UI Web/Android/iOS, API не меняется. Тесты не запускать: пользователь проверяет сам.

## Оценка перед выполнением

Вся локальная подзадача: сложность 2/10, трудоёмкость низкая, ≈85% пакета; LLM лёгкая. Типовая правка представления. Пользовательская приёмка — ≈15%.

## План и критерии завершения

- Дата и корзина в первой строке, суммы во второй.
- Короткий день недели перед датой без года.
- Суммы рядом, прежняя зачёркнутая сумма сохранена.
- Статус в составе заказа скрыт.
- Обновить номер и PROJECT_STATE; тесты не запускать.
