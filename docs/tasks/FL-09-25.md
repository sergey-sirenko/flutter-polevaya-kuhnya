## Что сделано

`MenuNetworkImage` на Web больше не использует режим HTML-картинки. Этот режим отдаёт ленивую текстуру: пока файл не лежит в кэше браузера, круг категории и фото блюда часто остаются чёрными или пустыми, а обновление страницы уже рисует готовый файл. Теперь байты декодируются целиком (`ImageRenderMethodForWeb.HttpGet`). Качество фильтра — среднее, как у `Image.network`: низкое на Web даёт чёрный круг при уменьшении большого JPEG. Появление без затухания, чтобы пустой кадр не оставался на экране. Если загрузка сорвалась, адрес выбрасывается из кэша и запрос повторяется ещё два раза, через 400 и 800 мс. Android и iOS по-прежнему кэшируют файл через тот же виджет; параметр Web на них не действует, среднее качество общее. Адрес картинки не менялся. Zak, сервер и Caddy не менялись.
