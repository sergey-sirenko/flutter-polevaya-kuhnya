## Что сделано

### Локальная модель сайта

Сайт выполняет `GET data/dishes.json` с `cache: no-store` и временным query-параметром. Клиент ожидает корневой объект `weeks[]`. Недели содержат `weekType` (`current`/`next` после нормализации), `weekNumber` и `days[]`. День содержит дату `date`, номер `dayNumber`, признак `hasDelivery` и `categories[]`.

Категория содержит `categoryId`, `categoryName`, `categoryOrder`, опциональный `categoryimagePath` и `dishes[]`. Блюдо используется с полями `dishId`, `dishName`, `menuOrder`, `price`, `servingweight`, `imagePath` и `ingredients.textDescription`. Рендер сортирует категории по `categoryOrder`, блюда по `menuOrder`, показывает название/вес/цену и сохраняет `dishId` в корзине. Отсутствие веса отображается как `Н/Д`, отсутствие изображения — локальная заглушка.

Нормализация сайта сортирует недели по минимальной валидной дате, оставляет две самые ранние, назначает им `current` и `next`. Даты сравниваются после обнуления времени; корзина ключуется датой `YYYY-MM-DD`. Это клиентское правило представления, а не утверждение о серверном часовом поясе.

В текущем checkout нет фактического `data/dishes.json`: присутствуют только служебные JSON-файлы и пустой `data/pictures/.gitkeep`. Поэтому значения блюд, категорий, цен, веса и путей изображений не извлекались из runtime-файла.

### Источник Zak/Mob

`КэшСеанс.ПолучитьМенюНаНеделю` выбирает из регистра `МенюНаДень` дату (`День`), ссылку номенклатуры, `ЦенаРеализации`, верхнюю группу, `ВесПорции`, `Ккал` и наименование. Для индивидуального меню контрагента цена берётся из `ЦенаПродажи`; строки объединяются с общим меню и сортируются по дню/номеру строки. Группа очищается от цифр и слова «БЛЮДА» для представления категории.

HTTP `POST /V1/Orders/menudates` возвращает только `success`, `message` и массив доступных ISO-дней (`menudates`) после проверки `token`; полное меню через этот endpoint не передаётся. Сайт сопоставляет эти даты с локальным `dishes.json` и запрещает отправку корзины для недоступных дней.

SOAP/WSDL `MAExchange` описывает `ПолучитьМенюДляЗагрузки`/`ПолучитьМенюДляЗагрузки2` и типы меню с полями `СоставМеню`, `Номенклатура`, `КлючНоменклатуры`, `День`, `ЦенаРеализации`, `ВидНоменклатуры`, `ВесПорции`, `Картинка`. Обмен Mob вызывает вариант `ПолучитьМенюДляЗагрузки2` для дат; отдельная загрузка номенклатуры (`ЗагрузитьНоменклатуру`) используется для данных блюд. Точные XDTO-значения, формат картинки и преобразование в JSON сайта без запуска обмена не проверены.

### Изображения

`js/api.js` строит URL `data/pictures/<imagePath>.jpg?v=<version>`, где `imagePath` хранится без расширения. Версия кэшируется в `localStorage.image_versions`; при ошибке загрузки `<img>` переключается на `assets/placeholders/dish-placeholder.png`. Модальное окно использует тот же путь. Категории могут иметь собственный `categoryimagePath`, но fallback и наличие файлов сервером не подтверждены.

### Черновая карта полей

| Назначение | Сайт JSON | Zak/1C или SOAP | Статус |
|---|---|---|---|
| Идентификатор блюда | `dishId` | `КлючНоменклатуры`/ссылка номенклатуры | Сопоставление по смыслу, формат ID не проверен |
| Дата меню | `days[].date` | `День` | Подтверждено чтением кода; timezone не проверен |
| Категория | `categoryId`, `categoryName`, `categoryOrder` | верхняя группа номенклатуры/представление группы | Название и очистка подтверждены; стабильный ID категории не найден |
| Цена | `price` | `ЦенаРеализации` или индивидуальная `ЦенаПродажи` | Подтвержден источник, формат округления не проверен |
| Вес | `servingweight` | `ВесПорции` | Подтверждено; единица измерения не зафиксирована |
| Состав/описание | `ingredients.textDescription` | SOAP/XDTO `Картинка` и номенклатура; текстовый состав в просмотренном кэше не найден | Требует отдельной сверки источника |
| Изображение | `imagePath`, `categoryimagePath` | SOAP/XDTO `Картинка` или выгрузка файлов | Имя/URL сайта подтверждены; серверное соответствие не проверено |

Это черновой контракт для анализа, не утверждённая схема Flutter. Не следует выдумывать обязательность состава, единицы веса, формат идентификатора или способ доставки картинок до получения фактического ответа и файлов.
