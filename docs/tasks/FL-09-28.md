# FL-09-28 — Не затирать блюда корзины пустой неделей

## Назначение

- Бизнес-цель: блюда текущей недели остаются в корзине, если следующая неделя повторяет те же даты без блюд.
- Требования ТЗ: FR-C4.
- Модуль: общий индекс меню для корзины, Android/iOS/Web.
- Ответственный: клиент Flutter.

## Входные условия

- Зависимые задачи: FL-05-07, FL-09-24. Живой `dishes.json` 29.09.2026: следующая неделя содержит даты текущей без `hasDelivery` и без блюд.
- Нужные контракты и решения: черновик сверяется с меню по дате и `dishId`.
- Окружение: локальные тесты.
- Ограничения выполнения и проверок: iOS не запускать. Android не пересобирать. Zak и Caddy не менять. Выкладка отдельно.

## Критерии завершения

Позиция текущей недели с тем же `dishId` не считается отсутствующей, если следующая неделя содержит эту дату без блюд. Итог считается по цене меню, тип недели остаётся `current`. Блюдо, которого нет ни в одной неделе, по-прежнему отмечается как отсутствующее.

## Что сделано

`indexMenuByDate` собирает блюда по дате. Пустой день не заменяет день, в котором блюда уже есть, и не меняет его тип недели. Проверка актуальности и расчёт корзины используют этот индекс. Сообщение об отсутствующем блюде больше не повторяет две одинаковые фразы. Android и iOS получают тот же код. Zak, сервер и Caddy не менялись.
