## Контракт представления v0.3

servingweight — необязательный текст для отображения: строка сохраняется после обрезки внешних пробелов, включая составные значения и обозначение штук. Пустая/пробельная строка, null и отсутствие поля означают неизвестный вес. Числовой JSON поддерживается для совместимости и переводится в текст. Объект, массив и bool отклоняются. В UI не добавлять непроверенные единицы и не суммировать составной вес. Цена, ID, даты, доступность заказа и API не меняются. MenuDish.servingWeight становится String?.
