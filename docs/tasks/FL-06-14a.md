# FL-06-14a — Быстрая сборка и выкладка тестового Web

## Назначение

- Бизнес-цель: повторяемо собрать Flutter Web и дать пользователю быстро проверить его на тестовом сайте.
- Требования: этап 6, FL-06-14, решение пользователя о проверке Web по SSH.
- Модуль: `tools/deploy_web_test.ps1`, `docs/testing-web-android.md`.

## Входные условия

- Действующий тестовый vhost: `flutter-test.obedmoscow.ru`, каталог `/var/www/flutter-test`.
- Сборка test использует API 1С и публичные меню/изображения `obedmoscow.ru/data/`.
- Ограничения: prod-vhost и Zak не менять, не выполнять бизнес-сценарии заказов; UI принимает пользователь в браузере.

## Критерии завершения

Одна команда собирает и публикует только следующий тестовый build. До замены сверяет SSH/Caddy и каталог, не допускает понижение build, проверяет SHA архива/файлов, сохраняет предыдущую версию и создаёт точную команду отката. Смена двух каталогов выполняется последовательными `mv`; между ними возможен краткий 404, Caddy reload не делается.

## Что сделано

Добавлен `tools/deploy_web_test.ps1`. По умолчанию он вызывает `build_web_test.ps1`, архивирует `build/web`, передаёт файлы по настроенному SSH, проверяет manifest и только затем заменяет каталог vhost двумя последовательными mv. Скрипт сохраняет tar и каталог предыдущей версии под `/var/backups/flutter/WEBTEST-<UTC stamp>`, проверяет Caddy без reload, хеши и публичный `version.json`, сохраняет `rollback.sh`. `-SkipBuild` публикует уже собранный Web; `-SshHost` меняет SSH-цель.

Полная инструкция добавлена в `docs/testing-web-android.md`. Старые исторические версии помечены по дате; состояние актуальной выкладки ведётся в PROJECT_STATE и карточках.

## Проверки

- Запланировано: PowerShell Parser, проверка ссылок и `git diff --check`.
- Публикация/выполнение SSH-скрипта не проверяются этой задачей.

Выкладка запрещена при совпадающей/более новой удалённой версии и при разделённых файловых системах `/var/www` и `/var/backups`; сервер до резервирования не меняется. `-SkipBuild` проверяет версию на сервере перед заменой активного каталога, после передачи пакета. Исправления скрипта и локальный прогон: [FL-06-14b](FL-06-14b.md).
