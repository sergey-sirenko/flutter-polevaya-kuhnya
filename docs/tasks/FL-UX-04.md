# FL-UX-04 — Компактные карточки блюд

Сложность 5/10, трудоёмкость средняя, LLM средняя: intrinsic-сетка, полный текст, скидки, количество и прокрутка.

## Результат

- [x] Фото 120 px на телефоне (лимит плана 160 px), 220 px на остальных экранах; BoxFit.contain показывает исходное изображение целиком.
- [x] Цена перенесена под название/вес; исходная скидочная цена слева, зачёркнута и на 20% меньше.
- [x] Цвета, шрифты, число колонок, ширины панелей, полные названия, пищевые показатели и доступ к составу сохранены.
- [x] Количество с областью 44 px, сохранение выбора/прокрутки, Back/resize и скидки проверены прежними и обновлёнными тестами.
- [x] Три дополнительные регрессии 390/1200/1440 с Arial проверяют ограничение фото и уменьшение высоты относительно старого квадратного фото с учётом добавленной цены.

Шаг версии +37. [Синтетические превью](../testing/FL-UX-04/README.md) подготовлены; сравнение одинаковых живых блюд на опубликованной версии остаётся в FL-UX-05.
