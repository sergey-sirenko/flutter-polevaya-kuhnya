# FL-UX-27a — Контракт многодневного набора и критерии

## Назначение и входные условия

Выполнить первый этап принятого пользователем плана FL-UX-27 от 02.10.2026. [Единая задача](../../../docs/tasks/FL-UX-27.md), [канонический клиентский контракт v1.0](../cart-multiday.md). Пользователь выбрал одновременную правку новых и существующих заказов, отправку только изменённых дней, восстановление после перезапуска и подтверждение отмен.

Локальная Flutter Web — 0.1.0+63. Уже существуют многодневная Cart, Orders/snapshot и атомарная ветка Orders/basket; обычный клиент пока подготавливает/отправляет одну дату. Платформенное поведение 1С анализом не подтверждено. Серверные форматы и семантика режима повтора сохраняются.

## Оценка перед выполнением

Вся a: сложность 3/10, трудоёмкость низкая, ≈10% этапа; LLM средняя. Основание — контракт поведения поверх существующих методов, критерии восстановления/отмен и совместимость. Внешние ожидания не входят в доли.

## Состояние и проверки

Завершена документально 02.10.2026. Контракт v1.0 и единая карточка созданы. Сверены CartEditController, CartPage, CartSubmitController, Router, хранилище повтора и существующие snapshot/basket. Существующий loadSnapshot требует 1–31 уникальную дату; серверная нормализация basket также ограничивает число дней 31. Успешная обычная отправка запрашивает снимок только для отправленных дат; при неизвестном исходе ID и тело сохраняются.

Проверки: 25 локальных Markdown-ссылок корректны, матрица содержит 16 сценариев, whitespace-ошибок новых документов/блоков и замечаний git diff --check нет. Все 8 контрольных SHA-256 для lib/test/web/android/ios, Zak/Konf и pubspec.yaml/lock совпали до/после a; прежнее содержимое 4 обновлённых файлов состояния сохранено побайтно. Платформа, HTTP, analyze/test/build и браузер не запускались: код не менялся. Коммитов, публикации и живых заказов/писем нет.

Реализована документация; функция многодневного обычного набора не реализована. Для Web/Android/iOS определён общий сценарий, исходники и настройки не менялись, мобильные сборки не выполнены; iOS runtime не запускался. Git/SHA и зависимости приведены в единой задаче.
