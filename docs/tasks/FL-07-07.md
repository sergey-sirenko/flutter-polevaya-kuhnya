# FL-07-07 — Настроить выпускные сборки

## Назначение и входные условия

- Цель: получить воспроизводимые Web release, Android AAB для магазинов и прямой Android APK с постоянным ID, корректной подписью и согласованными версиями.
- Требования: [дорожная карта, этап 7](../../Дорожная%20карта.md), [ТЗ §10](../../Техническое%20задание.md), [FL-07-03](FL-07-03.md), [FL-07-04](FL-07-04.md), [FL-07-05](FL-07-05.md).
- Окружение: локальный Flutter 3.47.1, Android SDK 36, Java 17; публичные URL окружений — [docs/environments.md](../environments.md). Подписи вне репозитория.
- Ограничения: по решению пользователя от 28.09.2026 FL-07-06 и iOS-часть этой подзадачи отложены до проверки через Codemagic после публикации Android. iOS не запускать. Не публиковать Web/APK, не загружать магазины или ИБ 1С, не создавать реальные заказы.

## Оценка перед выполнением

- Оценивается доступная часть Web/Android: сложность 7/10; трудоёмкость высокая, ≈7% этапа 7; LLM — сложная.
- Основание: изменение постоянного Android ID и подписи требует сборок и проверки итоговых сертификатов; цена ошибки при первом выпуске высока. Ввод паролей владельцем и ожидание кабинетов отдельно.

В доступном объёме: Web, AAB и APK собираются; AAB подписан upload key, APK — app signing key; оба имеют `ru.obedmoscow.polevayakuhnya`, версию из `pubspec.yaml`, корректный target API; секретов в репозитории нет. Полное завершение FL-07-07 требует iOS-сборку после возвращения к FL-07-06.
