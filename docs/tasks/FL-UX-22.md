# FL-UX-22 — Название, количество и фото главной

## Назначение

- Цель: название «Полевая кухня» в две строки рядом с логотипом, отсутствие кнопок количества без подготовленного дня заказа, компактное фото на широкой главной.
- Требования: прямое поручение пользователя и три снимка от 02.10.2026.
- Модуль: общий Flutter UI site/menu.
- Ответственный: Codex.

## Входные условия

Локальная и публичная Web 0.1.0+58. Существующее изменённое дерево сохраняется. API/Zak, бизнес-контроллеры и защита отправки не меняются. SSH выполняет пользователь; Android не пересобирать, iOS runtime не запускать. Localhost и локальные PNG не являются публичной приёмкой.

## Оценка перед выполнением

Вся локальная подзадача: сложность 3/10, трудоёмкость низкая, ≈85% отдельного пакета; LLM лёгкая. Основание: существующие компоненты, право изменения дня и готовые адаптивные проверки. Остаток ≈15% — пользовательская выкладка и визуальная приёмка; внешнее ожидание отдельно.

## Критерии завершения

Название «Полевая\nкухня» читается полностью на узкой/широкой шапке. Просмотр меню гостем или без подготовки дня не показывает −/количество/+; подготовленный доступный день позволяет менять количество, закрытый — только смотреть. Широкая витрина ограничена 440 px, мобильная занимает прежнюю ширину; стрелки, название, цена и contain сохранены.

## Что сделано

Название в site_widgets перенесено на две строки; доступное имя сохранено, измерения шапки учитывают перенос/масштаб. В menu_page количество скрывается без cartDayEditPermissionProvider или при закрытой дате; editable/locked защищают действия. В site_pages ширина карточки горизонтальной главной ограничена 440 px, она центрирована в своей колонке. Узкая раскладка, contain, стрелки и данные блюда сохранены. Тестовые фикстуры используют permission вместо обхода editable, сохраняя проверки временных блокировок. Публичный version.json при начале +58.
