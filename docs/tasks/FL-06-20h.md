# FL-06-20h — Сообщения и читаемость интерфейса

## Назначение

- Бизнес-цель: закрыть клиентские замечания W11 аудита законченности Web.
- Требования: FR-M3, FR-C1, FR-O1, NFR-UI-3/4/6.
- Модули: menu, cart/orders, site, profile; общий код Web/Android/iOS.
- Ответственный: LLM.

## Входные условия

- Зависимость: FL-06-20g; исходные замечания — [аудит W11](../web-completeness-audit.md#w11--p2--мелкие-состояния-и-читаемость).
- Ограничения: без публикации, изменений Zak/старого сайта, реальных заказов и iOS-тестирования. Мобильные сборки отложены; пользователь проверяет Web после отдельной SSH-выкладки.
- Сохранить накопленные изменения рабочего дерева; коммит пакета не поручен.

## Оценка перед выполнением

- Оценивается вся подзадача: сложность 4/10; трудоёмкость средняя, ≈4% этапа 6; LLM средняя.
- Основание: несколько экранов, форматирование и асинхронные внешние действия, widget-проверки доступны; внешний вид/платформенные обработчики принимает пользователь отдельно.

## Контракт отображения

- Источник цен, сумм, состава, имён и дат — существующие модели/API, без изменения серверных запросов и расчётных формул.
- День: `ДД.ММ.ГГГГ` для корзины, результата и истории; короткий `ДД.ММ` для вкладок меню/выбора дня. ISO-дата трактуется как календарный день источника, без timezone-сдвига. Неизвестная/неверная дата отображается как отсутствующее значение.
- Рубли: русская десятичная запятая, разделение тысяч, целая сумма без десятичной части, дробная — две цифры копеек. Округление только при отображении до копейки, расчёты не изменяются. Нулевые/неизвестные условия профиля сохраняют прежнее значение «не задано».
- Недоступное блюдо без известного имени объясняется человеку, технический ID не показывается как название. Идентификаторы корзины и API сохраняются.
- Полный состав доступен из карточки в прокручиваемом диалоге с закрытием, включая клавиатуру; компактный текст карточки сохраняется.
- Отказ/исключение открытия телефона, почты или внешнего файла показывает понятное сообщение. Поздний отказ после закрытия экрана не обращается к уничтоженному context. Внешнее действие выполняется только по нажатию.
- Все новые подписи/сообщения — AppStrings. Сообщения CartSubmitController уже централизованы ранее; серверные тексты не дублируются в клиенте.

## Что сделано

- [display_formats.dart](../../lib/shared/display_formats.dart): единые форматы рублёвых сумм, количества и календарных дат. Подключены к меню, корзине/серверному результату, истории и условиям профиля. Дробный лимит/скидка профиля больше не округляются до целого при показе; семантика нулевых/неизвестных условий сохранена.
- [menu_page.dart](../../lib/features/menu/menu_page.dart): полный состав в прокручиваемом диалоге с закрытием и Esc, цена с копейками, перенос цены/количества на узкой карточке через Wrap.
- [cart_page.dart](../../lib/features/cart/cart_page.dart): календарные даты, имена вместо ID; недоступное блюдо с понятным пояснением. Количество вынесено из trailing ListTile, кнопки ± получили tooltip. Цена и рассчитанный итог показаны отдельно, без знака математического равенства: существующая спецификация pricing округляет итог до целого рубля и учитывает скидки. Формулы/запросы/ID не изменены.
- [orders_page.dart](../../lib/features/cart/orders_page.dart): русские даты/суммы, количество без `.0`; короткие даты выбора дня используют тот же формат календаря.
- [external_link.dart](../../lib/shared/external_link.dart), [site_widgets.dart](../../lib/features/site/site_widgets.dart), [menu_excel.dart](../../lib/features/menu/menu_excel.dart): false/исключения внешнего обработчика дают понятный UI-отказ; после закрытия экрана context не используется. Телефон/почта и Excel покрыты общим обработчиком. Активных магазинных ссылок в текущем интерфейсе нет (FL-06-20d).
- Новые тексты/подписи — [AppStrings](../../lib/app/strings.dart). CartSubmitController просмотрен: свои сообщения уже централизованы в FL-06-20c, дополнительное изменение не требуется; серверные сообщения сохранены.
- 11 новых регрессий и обновление прежнего ожидания серверного итога `100.0 ₽` → `100 ₽`. Локальные проверки не используют рабочую базу или реальные внешние приложения.
- Общий код изменён для Web/Android/iOS. Web +6 собран с последними FL-06-20c…20h и источником меню/фото `https://obedmoscow.ru/data/`; не опубликован и не принят в браузере. Android APK/AAB остаются +4, пересборка/установка отложены. iOS не собиралась и не запускалась. Zak/старый сайт не менялись, предшествующие правки сохранены, коммит не выполнялся.
