# FL-UX-20 — Стрелки переключения блюда на главной

## Назначение

- Цель: переключать блюдо главной стрелками назад/вперёд.
- Требования: поручение пользователя от 01.10.2026 и снимок карточки главной.
- Модуль: общий Flutter UI главной и композиция данных в router.
- Ответственный: Codex.

## Входные условия

Локальная Web 0.1.0+56; публичный version.json при начале +55. Существующие изменения рабочего дерева, включая FL-UX-19, сохраняются. Использовать уже загруженные блюда выбранного дня с фотографиями; API/1С, корзину и бизнес-контроллеры не менять. SSH запускает пользователь; Android не пересобирать, iOS не запускать. Localhost не является приёмкой Web.

## Оценка перед выполнением

Вся подзадача: сложность 3/10, трудоёмкость низкая, ≈85% отдельного пакета; LLM лёгкая. Основание: локальное состояние карточки, готовые данные меню и адаптивные тесты. Остаток ≈15% — SSH/визуальная приёмка, внешнее ожидание отдельно.

## Критерии завершения

Назад/вперёд переключают блюдо по кругу на узкой и широкой главной. Фото contain на белом фоне, название и цена соответствуют блюду. При одном/нуле блюд стрелки скрыты; при смене дня список и показ сбрасываются на первый элемент. Resize сохраняет показанное блюдо. Листание не меняет день/корзину и не создаёт дополнительных бизнес-запросов.

## Что сделано

В `router.dart` вместо одного блюда передаётся список уже загруженных блюд с фото выбранного дня; прежнее начальное упорядочение категорий сохранено. В `site_pages.dart` добавлен презентационный SiteHomeDish и локальное состояние витрины по ID блюда, две стрелки 48×48 px с подсказками «Предыдущее блюдо»/«Следующее блюдо». Переходы циклические, фото/name/price выбираются из одной записи; contain на белом сохранён. Ключ дня сбрасывает показ при смене даты, resize сохраняет блюдо. При одном/нуле блюд стрелки скрыты; без фото остаётся прежний логотип. Фото загружается только для показанного блюда, переключение не вызывает бизнес-API и не меняет выбранную дату или корзину.

Расширена регрессия главной: оба направления и границы, блюда без фото, разные названия/цены/пути, resize 1440→390→1440, смена дня и возврат, отсутствие новых бизнес-запросов. Проверки компоновки стрелок: 320/390/650/1440, текст 1/1.6, длинное название, пустой/одиночный список. [Отчёт и превью](../testing/FL-UX-20/README.md).
