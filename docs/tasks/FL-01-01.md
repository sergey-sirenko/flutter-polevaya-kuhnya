# FL-01-01 — Подготовить отдельный репозиторий Flutter

## Назначение

- Бизнес-цель: отдельный учёт единого приложения без включения соседних проектов.
- Требования ТЗ: Ц3, раздел 3 и подготовка репозитория в этапе 0; сборки этим шагом не принимаются.
- Модуль: инфраструктура Flutter; [дорожная карта](<../../Дорожная карта.md>), этап 1.
- Ответственный: исполнитель Codex; пользователь подтверждает переход между подзадачами.

## Входные условия

- Зависимые задачи: документальное заключение [FL-00-17](FL-00-17.md), правила [FL-01-05](FL-01-05.md).
- Нужные контракты и решения: после вопроса о начале разработки с FL-01-01 пользователь ответил «продолжай». Требование отдельного подтверждения перед разработкой выполнено; остановки между подзадачами сохраняются. API-контракты для инициализации Git не требуются.
- Окружение: Windows, PowerShell; `E:\GIT\HlebSol\Flutter`. До начала собственного Git нет; `.git` в HlebSol отсутствует. Настройка `init.defaultBranch` — `master`.
- Ограничения выполнения и проверок: только локальные файлы и Git. Каркас, установка инструментов, приложения, браузер, тесты, сервер, рабочая база и сетевые запросы не входят в задачу. Исходные документы и изменения сайта сохранить. После одной подзадачи остановиться.
