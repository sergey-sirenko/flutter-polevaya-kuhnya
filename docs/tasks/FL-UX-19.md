# FL-UX-19 — Категории в адаптивном меню и равные карточки главной

## Назначение

- Цель: убрать верхнюю полосу выбора категорий в адаптивном меню и сделать все карточки категорий главной одинаковыми по размеру.
- Требования: поручение пользователя от 01.10.2026 и два приложенных снимка.
- Модуль: общий Flutter UI меню/главной Web/Android/iOS.
- Ответственный: Codex.

## Входные условия

FL-DESIGN-02 внедрена. Локальная и публичная Web 0.1.0+55 (version.json проверен). Сохранить существующие изменения рабочего дерева, нижний выбор категорий и широкую левую панель. API/Zak и бизнес-логика не затрагиваются. SSH запускает пользователь; Android не пересобирать, iOS не запускать. Localhost не считается приёмкой Web.
