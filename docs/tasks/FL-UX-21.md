# FL-UX-21 — Автоматическое обновление Web без сохранения данных

## Назначение

- Цель: новая Web-версия применяется перезагрузкой вкладки автоматически.
- Требование: прямое поручение пользователя 01.10.2026; сохранять данные перед обновлением не нужно.
- Модуль: app, core/platform, Web bootstrap.
- Ответственный: Codex.

## Входные условия

Локальная/публичная +57. Поручение заменяет прежнее требование сохранения перед Web-обновлением в ADR-9 только для этого действия. Не добавлять сохранение/ожидание заказа/подтверждение; не очищать существующие token/draft/pending хранилища и не повторять POST. API/Zak и native распространение не менять. SSH запускает пользователь, Android не пересобирать, iOS не запускать. Существующие изменения сохраняются.

## Оценка перед выполнением

Вся подзадача: 5/10, трудоёмкость средняя, ≈85% отдельного пакета; LLM средняя. Основание: фоновая проверка, conditional Web-адаптер, свежий bootstrap/main.dart.js и защита циклов. Остаток ≈15% — пользовательская SSH-выкладка/браузерная приёмка, внешнее ожидание отдельно.

## План

- [x] Web-only проверка каждые 10 секунд, на старте и при возврате во вкладку.
- [x] Автоматический переход текущего адреса при валидном новом Web release, без дополнительного сохранения.
- [x] Однократная попытка на release; защита кэша index/bootstrap/main и повторов.
- [x] Проверки ошибок/таймаутов/позднего ответа/native/URL и сборка +58.
- [x] ADR/контракт/состояние/отчёт и остановка.

## Критерии завершения

Публикация нового release обнаруживается активной вкладкой не позднее следующей проверки (10 секунд плюс сеть); при foreground — сразу. Только валидный release > compiled current; неизвестная/старая версия не перезагружает. Нативные клиенты не перезагружаются. Адрес/path/query/fragment сохраняются с техническим маркером; bootstrap/main загружаются с новым URL. Ошибка сети не блокирует ввод, параллельные проверки и бесконечные reload исключены. Сохранение/очистка бизнес-данных и POST не добавляются.

## Состояние

Реализовано и проверено локально, release Web 0.1.0+58 готов; публикации нет. Analyze чистый, 76 тестов прошли; bootstrap URL-проверки и готовый inline index прошли. Первое обновление вкладок +57 пользователь выполняет вручную: прежний код механизма не содержит. Завершено 02.10.2026.

## Что сделано

`core/platform/web_auto_update.dart` использует прежний валидатор/repository policy, проверяет release > compiled current, стартует после первой проверки gate и проверяет каждые 10 секунд/foreground. Скрытые вкладки не опрашиваются; при возвращении — немедленный GET. При старте/ручном retry новый release применяется сразу, фоновая проверка не меняет gate и не блокирует ввод. Один запрос одновременно, ошибки/поздние ответы после dispose не перезагружают.

Conditional Web-адаптер в core/platform, канал определяется distribution.dart. Нативный адаптер no-op. Web reload — location.replace текущего адреса, сохраняются route/query (включая повторные параметры)/fragment; добавляется `_app_update`. Маркер release в sessionStorage и URL, плюс process-set попыток, предотвращают цикл при прежнем коде и недоступном sessionStorage. Это только метаданные попытки, не сохранение бизнес-данных. Дополнительного сохранения, ожидания submission, очистки токенов/draft/pending или POST нет.

Web index включает inline Flutter bootstrap; main.dart.js всегда получает stamp сборки, после автообновления — также release-маркер. Новый worker не регистрируется, глобальные кэши/чужие вкладки не очищаются. `web` 1.1.1 переведён из transitive в direct dependency офлайн; остальные версии сохранены. Принята Web-часть ADR-9 и обновлена действующая часть контракта. [Отчёт](../testing/FL-UX-21/README.md).
