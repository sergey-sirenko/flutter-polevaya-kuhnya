# FL-UX-46 — Восстановление открытого заказа после F5

## Назначение и входные условия
09.10.2026 пользователь сообщил: после F5 открытого подтверждённого заказа видна пустая корзина с предложением открыть день в заказах. В _loadSavedChanges сохраняемый исходный набор без changedDates отбрасывается; CartPage автоматически восстанавливает только recovery.

## Оценка перед выполнением
Вся подзадача: сложность 3/10, трудоёмкость низкая, LLM средняя — асинхронное чтение с защитой сессии и проверкой серверных версий. Отдельный UX-пакет вне этапа. Сохранённое ограничение: тесты/превью и мобильные сборки не запускать; статический анализ и локальная Web-сборка разрешены. Публичная при начале +85, целевая +86.

## План и критерии завершения
- В корзине после восстановления сессии читать также открытый набор без локальных правок.
- Сохранить строгую проверку владельца, версий, исходного состава и доступности всех дат.
- Не показывать неизменённый набор как незавершённые правки на остальных страницах.
- Format/analyze/diff-check/version-policy, Web-сборка и PROJECT_STATE.

## Что сделано
В cart_edit_controller.dart у resume добавлен опциональный restoreOpenedCart. При отсутствии recovery/активного набора он читает исходный CartWorkSnapshot из очереди хранилища текущего login/device. После чтения проверяются epoch, текущий sessionApi, отсутствие активной подготовки и блокировок. Набор становится recovery и проходит прежнюю _prepare(saved: work): обновление меню, серверный snapshot, ownerScope, версии/исходный состав и доступность всех дней. При ошибке чтения показывается recoveryError; при конфликте исходные данные сохраняются.

CartPage один раз автоматически пытается восстановить набор после завершения чтения/сессии и при отсутствии активного редактирования. Во время восстановления показан индикатор, после успеха выбирается сохранённая дата меню. Прежние проверки актуальности URI сохранены. На остальных страницах _loadSavedChanges продолжает возвращать только наборы с changedDates, поэтому неизменённый открытый заказ не выдаётся за незавершённые правки.

pubspec.yaml и оба build-поля web/version.json — 1.0.0+86. Минимум policy, Android/iOS null и пользовательские изменения сохранены. API/Zak/серверные заказы не изменялись. Коммит/push не выполнялись.
