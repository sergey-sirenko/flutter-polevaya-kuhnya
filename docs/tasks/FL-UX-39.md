# FL-UX-39 — Автопродолжение сохранённого набора во всех местах показа

## Назначение
По поручению пользователя вместо «Есть сохранённый набор» автоматически выполнить продолжение и показать корзину, где пользователь выберет Отменить/Сохранить.

## Входные условия и оценка
В +78 автовосстановление было только на CartPage. Все места показа обычного сохранённого набора используют CartWorkBanner. Вся подзадача: сложность 3/10, трудоёмкость низкая, LLM средняя; навигация, блокировки и предотвращение цикла ошибок. Отдельный UX-пакет вне этапа. Тесты/превью не запускать по сохранённому ограничению; сохранённые правки и серверную проверку не обходить.

## План и критерии
- Добавить однократное автоматическое продолжение в общий баннер с прежним onReady.
- Не дублировать уже существующее восстановление CartPage.
- Во время автоматического продолжения показать загрузку, при ошибке сохранить ручной повтор и причину.
- Analyze/diff-check/version-policy/Web-сборка; обновить состояние и остановиться.

## Что сделано
CartWorkBanner стал ConsumerStatefulWidget: появление recovery/blocked инициирует одну автоматическую попытку resume после снятия блокировок. Пока она выполняется, вместо вопроса показывается загрузка. Используются прежние синхронизация даты меню и onReady: в заказах переход в корзину, на экране подготовки открытие восстановленного набора. При уходе с маршрута поздние синхронизация/переход не выполняются. Повторная попытка автоматически не запускается при том же неудачном восстановлении; новое появление сохранённого набора после завершённой предыдущей работы допускает новую попытку.

CartPage сохраняет собственное автовосстановление +78, поэтому её экземпляр баннера получает autoRestore=false и не запускает дублирующий resume. Ошибки баннера показаны общим компонентом, дублирующий вывод в router.dart убран. Подтверждение сброса и кнопки Отменить/Сохранить корзины сохранены, корзина автоматически не отправляется. Проверки серверных версий и сохранность правок не обходятся. Отдельный механизм повторённой корзины не менялся.

Версия pubspec.yaml и обоих build-полей web/version.json — 1.0.0+79; минимум policy и null Android/iOS сохранены. Общий UI Web/Android/iOS; мобильные сборки/runtime не выполнялись, API/Zak/пользовательские данные агентом не менялись.
