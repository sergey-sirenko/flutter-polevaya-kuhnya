# FL-UX-15 — Подписи календаря заказов

## Назначение

Кнопка повтора с видимой надписью «Повторить заказ». В карточках дней убрать известные состояния «Закрыт»/«Доступен», сохранив цвета; дата и полное имя дня одной надписью «05.10 Понедельник», слева (уточнение пользователя).

Локальная и публичная Web +50. Цвета, выбор, расчёты и ограничения действий сохраняются. Ожидание/ошибка доступности и пояснение выбранного дня сохраняются. Общий UI Web/Android/iOS; iOS не запускать, SSH выполняет пользователь. API/1С не меняются.
