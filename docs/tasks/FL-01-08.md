# FL-01-08 — Создать структуру приложения

## Назначение

- Бизнес-цель: отделить сборку приложения от первого модуля и подготовить понятную структуру для следующих функций.
- Требования ТЗ: разделы 4.1 и 8, Ц3, ADR-4/5/7; [этап 1 дорожной карты](<../../Дорожная карта.md>).
- Модуль: `lib/main.dart`, `lib/app/`, `lib/core/config/`, `lib/features/site/`.
- Ответственный: Codex.

## Входные условия

- Зависимые задачи: FL-01-03–07 выполнены; в FL-01-02 выбран способ iOS-сборки, практические проверки впереди.
- Нужные контракты и решения: [ARCHITECTURE.md](../../ARCHITECTURE.md), разделы 2–3 и ADR-8. Первый экран статический и не вызывает API; бизнес-контракт для него не требуется.
- Окружение: Flutter 3.47.1, Dart 3.13.1; Git `master` без коммитов и remote.
- Ограничения выполнения и проверок: не менять 1С, соседние проекты и тестовые данные; не создавать пустые каталоги и прикладные слои без потребности. Платформенные сборки не выполняются в этой задаче; выбранная iOS-среда ещё не проверена.
