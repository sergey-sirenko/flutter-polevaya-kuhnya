# FL-UX-52 — Автоматическое принятие актуального заказа при конфликте

## Назначение
По прямому поручению 11.10.2026 выполнять единственное действие показанного конфликта автоматически: сбрасывать локальные правки обычного набора и загружать актуальный состав доступных дат без «Оставить как есть» и подтверждения. Общий код Web/Android/iOS; ответственный Codex.

## Входные условия
Исходная локальная и публичная test версия +91. Поручение отменяет необходимость подтверждения только при подтверждённом конфликте исходной revision/состава обычного набора. Серверные заказы не отменять. Ошибки сети, владельца, формата и блокировки pending/W07 не являются разрешением сброса. Накопленные FL-UX-48…51 сохранить.

## Оценка перед выполнением
Вся задача: сложность 3/10; трудоёмкость низкая; LLM средняя. Отдельная задача без определённой доли этапа. Основание: атомарный снимок, сохранение до применения, асинхронные блокировки и многодневные правки.

## План и критерии завершения
- Проверить весь snapshot; при конфликте отбросить локальные количества всего обычного набора и взять актуальные серверные составы.
- Сначала сохранить новый снимок, затем применить корзину; без дополнительного запроса/кнопки/диалога.
- Закрытые даты исключаются по FL-UX-49. Ошибки/смена владельца/неизвестный исход сохраняют прежние защиты.
- Целевые тесты, analyze, diff/version policy и test Web +92; обновить PROJECT_STATE.

## Результат 11.10.2026
Реализация завершена: _prepare после полной проверки snapshot определяет конфликт любой исходной revision/состава доступной даты и автоматически использует актуальные серверные количества всего обычного набора вместо локальных правок. Свежие версии/исходные составы/имена сохраняются до применения корзины. Закрытые дни исключаются прежним фильтром. Выбор доступной даты сохраняется; если выбранная дата закрыта, выбирается первая доступная. При успехе набор активен, changedDates пуст, поэтому восстановление само ничего не отправляет и не отменяет.

Промежуточное состояние recoveryConflict и блокирующий текст/кнопка/диалог конфликта удалены. CartWorkBanner и CartPage используют прежнее автоматическое восстановление. «Оставить как есть» с подтверждением остаётся для ручного выбора, когда есть альтернатива восстановления. Автоматический сброс относится только к показанному конфликту обычного набора, а не ко всем одиночным кнопкам приложения. Пользовательское поручение заменяет подтверждение FL-UX-50/51 для этого случая.

Сбой сети/формата/записи и чужой ownerScope сохраняют прежние правки. Проверки epoch/API/generation, pending/unknown и W07 сохранены. Режим повтора и серверные контракты/данные не менялись. Конкретные серверные данные пользователя не читались, использовались синтетические тестовые ответы.
