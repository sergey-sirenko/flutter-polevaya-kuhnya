## Что сделано

Прочитаны общие и локальные инструкции, точка остановки и источники адресов. Сайт использует `https://hleb-sol.su/Zakaz_http/hs/Obmen/V1/...` для HTTP 1С; меню читает из `data/dishes.json`, фото из `data/pictures/`. Новый Flutter test-vhost пока не выдаёт `/data/*` и не подключён к API через локальный прокси. Это не отдельная база; при тестировании используются выделенные тестовые пользователи рабочей 1С.

Добавлены [AppConfig](../../lib/core/config/app_config.dart), [проверки](../../test/core/config/app_config_test.dart) и [инструкция окружений](../environments.md). В `main.dart` конфигурация читается до запуска UI; при отсутствии или неверных значениях приложение выдаёт ошибку вместо молчаливого выбора адреса. API и каталог данных являются разными HTTPS-базами с завершающим `/`; встроенных адресов по умолчанию нет. Метка «тест» относится к сборке, не к отдельной базе 1С. Публичные примеры команд содержат только адреса, без реквизитов.
