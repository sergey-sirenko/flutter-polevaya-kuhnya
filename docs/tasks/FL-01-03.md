## Назначение

- Бизнес-цель: получить один исходный Flutter-проект для Web, Android и будущей iOS-сборки, сохранив подготовленные документы.
- Требования ТЗ: Ц3, разделы 4.3 и 8; [этап 1 дорожной карты](<../../Дорожная карта.md>).
- Модуль: каркас приложения и платформенные шаблоны.
- Ответственный: Codex.

## Входные условия

- Зависимые задачи: [FL-01-01](FL-01-01.md) завершена; [FL-01-02](FL-01-02.md) частична из-за отложенного пользователем выбора iOS-среды. Web/Android SDK установлены.

- Окружение: Windows, отдельный Git Flutter `master` без коммитов/remote; Flutter 3.47.1, Dart 3.13.1, Android SDK API 36.
- Ограничения выполнения и проверок: сохранить все существующие документы и файлы; создать только Web, Android, iOS, без Windows/macOS/Linux. iOS-сборка на Windows не выполняется. Приложение не подключать к 1С, не публиковать, реальные заказы не создавать. После подзадачи остановиться.
