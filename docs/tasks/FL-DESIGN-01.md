# FL-DESIGN-01 — Три примера дизайна с новым логотипом

## Назначение

- Цель: сравнить три цельных направления оформления на реальных блюдах сайта до изменения Flutter.
- Поручение: реализовать план трёх HTML/CSS-прототипов, 12 PNG, снимка меню и адаптивных проверок.
- Модуль: только docs/design/FL-DESIGN-01 и документация задачи.
- Ответственный: Codex; выполняет самостоятельно.

## Входные условия

- Новый зелёный логотип assets/branding/app-logo-cb1bbbb6c0df.png.
- Публичный источник https://obedmoscow.ru/data/dishes.json и pictures/<imagePath>.jpg.
- Общий день сравнения 05.10.2026. Фото на белом фоне, без изменения и обрезания блюда.
- Flutter 0.1.0+54, API, Zak, версии/ресурсы приложения не меняются. Публикация не входит в задачу. Android не пересобирать; iOS не запускать.
- Ранее визуально осмотрена публичная Web +54; профиль/история в текущей сессии недоступны из-за ошибки проверки входа.

## Оценка перед выполнением

- Вся отдельная подзадача: сложность 4/10, трудоёмкость средняя; LLM средняя.
- Основание: согласованность данных и трёх вариантов, адаптивная геометрия, визуальные проверки. Внешнего ожидания нет.

## Что сделано

[Каталог](../design/FL-DESIGN-01/index.html), [описание и анализ](../design/FL-DESIGN-01/README.md), [протокол](../design/FL-DESIGN-01/verification.json). 12 PNG и два листа сравнения, исходный JSON на 10 дней, 436 оригинальных JPEG (25 930 235 байт), прозрачный логотип и манифест SHA-256. Все варианты используют один день 05.10.2026 и исходные цены без персональных скидок.

Три направления: Белая кухня (рекомендовано), Тёплый обед, Зелёный стандарт. Работают локальные количества по дням, предварительная сумма, календарь/категории/состав, образцы формы/профиля/сообщений. Встроенный текст 160% воспроизводим без дополнительных установок. На телефоне компактная навигация: выбор дня снизу, категории над блюдами, состав по фото.

## Проверки

| Проверка | Результат |
|---|---|
| 3 варианта × 2 страницы × 7 ширин × 2 масштаба | 84 случая: нет горизонтального переполнения, зон управления ниже 44 px, шрифтов ниже 14 px или незагруженных фото |
| 12 финальных экранов, 1440×1080 / 390×844 | Сняты в браузере, PNG экспортированы и визуально просмотрены; выделение не меняет высоту карточки |
| Корзина каждого варианта | 2 × 110 + 135 = 355 ₽; resize 390→1200 сохраняет состав; другой день 0 ₽, возврат 355 ₽ |
| Форма 390×480 | Ввод «Пример», без переполнения; Escape закрывает окно |
| Нижняя панель, последняя кнопка каталога | Добавление гренок доступно выше итога; 425 ₽ после добавления; заказ не отправлен |
| 436 JPEG, JSON и логотип | Все открываются, SHA-256 совпадают с манифестом; оригинальные фото не обработаны |
| node --check prototype.js | Пройдено |

PNG получены из браузерных JPEG с пропорциональным восстановлением размеров viewport, без обрезания/перерисовки; метаданные сохранены. Первый сетевой этап urllib дал таймауты, а стандартный Windows Python не содержал tzdata. JSON получен через Invoke-WebRequest; все JPEG успешно сохранены curl.exe, время фиксировано UTC+3 без дополнительной установки. Ограничения сняты, отсутствующих ресурсов нет.

Web/Android/iOS код общий и не менялся. Flutter analyze/test/build не запускались; Android не пересобран/не проверен на устройстве, iOS не запускалась. Геометрия формы не является приёмкой физической клавиатуры. API, 1С, реальные заказы/письма, коммиты и публикация не затрагивались.
