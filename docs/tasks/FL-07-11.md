## Фактический результат 28.09.2026

- Подготовлены [единые тексты ru-RU](../store-listings/ru-RU.json), [таблица переноса в магазины и условия публикации](../store-listings/README.md), [результаты лимитов](../store-listings/validation.json).
- Name/short/full/subtitle проверены по официальным лимитам. Apple keywords проверены по лимиту 100 UTF-8 байт (официальная страница именно указывает bytes). Подробные источники и дата проверки записаны в README.
- Контакты совпали с lib/features/site/site_content.dart и публичным рабочим сайтом. HTTP корня 200, HTML содержит #contacts/#terms, опубликованный router.js предусматривает эти маршруты. Браузер, звонки и письма не использовались.
- Support URL предложен на действующем obedmoscow.ru/#contacts. Privacy URL оставлен null: рабочее #terms содержит формулировку о продаже ПО, Flutter /privacy имеет иной текст и не принят на постоянном рабочем URL. Требуется согласовать реальное содержание/URL; не подменять отсутствующую политику тестовым доменом или договором.
- Общее описание отражает реализованные меню, вход с кодом менеджера, многодневную корзину, историю/повтор. Не обещаются offline, push, онлайн-оплата или готовая самостоятельная регистрация без менеджера. Сценарий заказа/истории перед публикацией требует живой приёмки; текст не объявляет её выполненной.
- Действующие карточки старого приложения из SiteContent не использованы как адрес нового Flutter-приложения. Публикация материалов в кабинетах не выполнялась.
- Проверены JSON, символы/байты, относительные ссылки и git diff --check. Код приложения/1С, тесты, сборки, iOS, заказы, письма и сайты не запускались/не менялись. Веб-запросы только read-only для документов/контактов.
- Указание пользователя «пересборку пропусти» сохранено: FL-07-10a не начиналась, Web/Android +4 не пересобирались; знак ещё только в исходниках. Описания хранятся как общий набор для платформ, изменения UI не требуются.
- Полное согласование FL-07-11 не закрыто: владельцу принять тексты/контакты и утвердить Privacy URL; готовность к публикации зависит также от FR-A6/FL-07-12 и живой приёмки. Накопленные исходники в Git остаются отдельным открытым пунктом.
