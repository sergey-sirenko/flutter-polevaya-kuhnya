# FL-UX-28 — Общие действия и компактная корзина

## Назначение и входные условия

Поручение пользователя от 02.10.2026 и пять снимков интерфейса: скрыть отчёты подготовки в корзине/заказах, вкладки «Пн? / 05.10», убрать общий предварительный итог и справку, поместить общие «Отменить»/«Сохранить» рядом с заголовком. Отмена сбрасывает локальные правки всех дней; сохранение отправляет изменённые дни одним basket. Оба действия завершаются переходом к заказам; успех — всплывающее уведомление без отдельного экрана и сравнения округлённых сумм.

Основа: [FL-UX-27b](FL-UX-27b.md), [контракт](../cart-multiday.md). Общий код Web/Android/iOS; API/Zak не менять, Android не пересобирать, iOS runtime не запускать. SSH выполняет пользователь; живых записей/входов/писем/коммитов нет.

## Оценка перед выполнением

Вся локальная подзадача: сложность 4/10; трудоёмкость средняя, ≈85% отдельного пакета правки и приёмки; LLM средняя. Основание — безопасная отмена, переход после принятой квитанции и адаптивный заголовок. Пользовательская приёмка ≈15%, внешнее ожидание SSH отдельно.
