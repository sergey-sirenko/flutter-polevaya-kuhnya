## Препятствия и границы

Первый новый release должен быть проверен пользователем на Flutter test до переноса на основной сайт. Test/prod отличаются окружением, URL политики и SEO; переносится один принятый source commit с фиксированными зависимостями, не test-бинарник с APP_ENV=test.
