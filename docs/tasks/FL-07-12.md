# FL-07-12 — Сведения о данных для магазинов

## Назначение

- Бизнес-цель: обоснованные черновики Google Data Safety, Apple App Privacy и сведений RuStore.
- Требования: ST-AND-4, ST-iOS-2/3, FR-A6, ТЗ §10.4; дорожная карта этап 7.
- Модуль: документация деклараций; сервер/клиент не изменяются.
- Ответственный: LLM; владелец подтверждает серверную обработку и вносит ответы в кабинеты.

## Входные условия

- Зависимости: FL-07-11, контракты API, фактический клиент +4 и зависимости pubspec.lock.
- Объём: статический аудит Flutter, API-контрактов и локальных платформенных исходников; официальные правила магазинов.
- Ограничения: без запуска приложений/сборок/iOS, входа в кабинеты, живых API с реквизитами, писем, заказов, изменения 1С и публикации. Пересборка пропущена пользователем.

## Оценка перед выполнением

- Вся подзадача; сложность 6/10, трудоёмкость средняя, ≈5% этапа 7.
- LLM сложная: реальные потоки, правила трёх магазинов, открытые политика и удаление; цена неверной декларации.
- Внешнее ожидание: сведения владельца о серверах/хранении/подрядчиках, приёмка и кабинеты.
