# FL-UX-40 — Убрать список пропущенных дней

## Назначение
По снимку пользователя убрать красные сообщения вида «2026-10-05: день закрыт.» после успешной подготовки набора.

## Входные условия и оценка
Список формируется из excluded в CartEditController._prepare для других недоступных дней при успешной подготовке. Вся правка: сложность 1/10, трудоёмкость низкая, LLM лёгкая; отделить информационный список от ошибки выбранного дня/восстановления. Отдельный UX-пакет вне этапа. Тесты/превью не запускать по сохранённому ограничению.

## План и критерии
- Не формировать информационное message из пропущенных дней при успешной подготовке.
- Сохранить исключение недоступных дней и ошибки выбранного дня/сохранённого набора.
- Поднять сборку, analyze/diff-check/version-policy/Web-сборка.
- Обновить PROJECT_STATE и остановиться перед выкладкой/приёмкой.
