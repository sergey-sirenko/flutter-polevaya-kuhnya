# FL-DESIGN-02 — Перенос «Белой кухни» в Flutter

## Назначение

- Цель: единое оформление приложения по выбранному пользователем варианту 1.
- Поручение: составить план и выполнить доработку, 01.10.2026.
- Модуль: общая тема, оболочка, главная, каталог и общие поверхности Web/Android/iOS.
- Ответственный: Codex.

## Входные условия

Выбран [вариант Белая кухня](../design/FL-DESIGN-01/1-white-kitchen.html). Текущая версия 0.1.0+54. Предшествующие незакоммиченные изменения сохраняются. API/1С, доступ, расчёты, скидки, revisions, pending и восстановление заказа остаются действующими. Фотографии целиком на белом фоне. Android не пересобирать, iOS не запускать. SSH выполняет пользователь; локальный просмотр не является приёмкой публичной Web.

## Оценка перед выполнением

Вся подзадача: сложность 5/10, трудоёмкость средняя, ≈85% этапа переноса; LLM средняя. Оценка прежнего документального согласования 3/10 уточнена: новое поручение включает реализацию и проверки. Оставшиеся ≈15% — FL-DESIGN-03, публикация пользователем и приёмка. Основание — общая тема и адаптивная геометрия нескольких экранов при сохранении бизнес-логики. Внешнего ожидания для локальной реализации нет.

## План

- [x] Общие токены: белый #FFFFFF, зелёный #305F3D, тёмный текст, светлые зелёные поверхности, радиус 12 px, вторичный золотистый акцент.
- [x] Каталог: панели 224/400 px; 2 карточки на 1200 и 3 на 1440; безопасные 320/390/600/768/1024 и текст 1.6.

- [x] Главная с реальным блюдом текущего меню; единые формы, профиль, корзина, календарь, сообщения и навигация.
- [x] Analyze, затронутые/полные тесты, визуальные превью; повышение версии на один шаг и release Web с действующими источниками.
- [x] Обновление PROJECT_STATE/AGENTS/дорожной карты, отчёт и остановка до выкладки пользователем.

Нет изменений контроллеров/репозиториев заказа и API. Локальная сборка и фактические проверки отдельно от публикации и платформенной приёмки.
