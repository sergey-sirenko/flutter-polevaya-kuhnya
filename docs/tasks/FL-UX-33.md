# FL-UX-33 — Повтор заказа рядом с выбранной датой

## Назначение
По снимку пользователя перенести «Повторить заказ» из шапки справа от выбранной даты под итогами недель.

## Входные условия и оценка
Общий интерфейс OrdersPage для Web/Android/iOS. Вся подзадача: сложность 2/10, трудоёмкость низкая, LLM лёгкая. Отдельная UX-правка вне этапного пакета; доля старого этапа не назначается. Существующие обработчик и блокировки сохраняются. Выкладку тестового Web запускает пользователь.

## План
- Перенести существующую кнопку в строку выбранного дня.
- Учитывать ширину панели при размещении даты и кнопки.
- Поднять номер сборки на один; проверить анализатор и согласованность версии.
- Обновить PROJECT_STATE и зафиксировать остаток приёмки.

## Критерии завершения
В шапке кнопки нет; справа от даты выбранного дня есть прежнее действие с прежним ключом и блокировками. Живая приёмка после выкладки пользователем.
