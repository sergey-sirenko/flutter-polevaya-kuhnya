### Уточнение требований платформ

Для Flutter 3.47 официально поддерживаются Android от API 24 и iOS от 15. Таким образом, условие ТЗ «iOS 13 или выше, если требует Flutter» для выбранного набора означает **iOS 15+**; Android остаётся **API 24+**. SDK Platform 36 для компиляции не означает повышение минимальной Android до 36. ТЗ сохранено; фактические deployment target/minSdk будут записаны при создании проекта. Источник: [поддерживаемые платформы Flutter](https://docs.flutter.dev/reference/supported-platforms).

Первоначально выбор iOS-среды был отложен. По новому указанию пользователя 26.09.2026 выбран **Codemagic: iOS-сборка на облачном macOS-хосте и Codemagic App Preview для запуска iOS-симулятора в браузере Windows**. Для предпросмотра требуется debug `.app` с целью `iPhoneSimulator` (`--simulator`); неподписанный артефакт симулятора не заменяет сборку для реального iPhone или App Store. В App Preview доступ предусмотрен для команд: пробные минуты и последующая оплата зависят от тарифа сервиса. Конкретные версии Xcode/iOS SDK, доступ к учётной записи, размещение исходников в удалённом Git, конфигурация сборки и подпись ещё не проверены. Git Flutter пока не имеет коммитов и remote. Источники: [сборка Flutter в Codemagic](https://docs.codemagic.io/flutter-configuration/flutter-projects/), [App Preview](https://docs.codemagic.io/flutter-testing/app-preview/), [настройка iOS в Flutter](https://docs.flutter.dev/platform-integration/ios/setup).
