# FL-UX-18b — Серверный снимок заказа

## Назначение и входные условия

По поручению «продолжай» реализовать серверную часть [FL-UX-18](../../../docs/tasks/FL-UX-18.md) по [контракту snapshot v1.0](../../../Zak/docs/order-snapshot.md). Два BSL-модуля Zak: ОбменHTTP и HTTP-сервис Obmen. Метаданные/Flutter не менять; прежние рабочие правки сохранять. Режим совместимости конфигурации 8.3.12, запуск платформы/загрузка базы/живые заказы не разрешены в этом этапе.

## Оценка перед выполнением

5/10, трудоёмкость средняя, ≈40% пакета; LLM средняя. Основание — общий материал состава и хеша, проекция сотрудника/условий и совместимость старых методов.

## Критерии завершения

Метод читает одним HTTP-обращением все поля контракта. Состав и хеш используют один материал; повторных запросов документов по дням нет. Старый хеш сохраняется, basket продолжает сравнивать revision. Заказы/сессии/привязки не записываются. Платформенная проверка согласованности отдельно, не выдается за выполненную.
