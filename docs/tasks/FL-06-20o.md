## Что сделано

- APP_VERSION_URL обязателен и независим от DATA_BASE_URL; все fixtures и текущие команды/скрипты обновлены для среды. Меню/фото остаются obedmoscow.ru/data/.
- AppVersion и Policy строго проверяют версии, schema/environment, общий минимум, все каналы, совпадение идентификации Web и URL. Web URL — HTTPS-корень origin конфигурации. Native allowlist production пуст до принятия конкретных ссылок: мобильные releases пока только null. В синтетических тестах — точное совпадение одобренного URL продукта.
- ApiClient получает только настроенный /version.json: GET/Accept, без body/токена/данных сессии, followRedirects=false; 5 секунд, уникальный служебный check, без retries/постоянного кэша. JSON проверяется до сохранения различия дробных/экспоненциальных лексем для JS; обычные ответы API/меню не меняются.
- Repository → ручной Notifier: checking/current/available/required/unknown; required сохраняется при повторе/ошибке, свежий меньший минимум принимается, поколение проверки защищает от старых ответов/смены зависимости/dispose. Неизвестная текущая версия не заменяется серверной.
- Старый compareAppVersion исправлен на кортеж; встроенная подпись текущей сборки сохранена. Controller не подключён к startup/router/UI: запрос сам не запускается, действие обновления отсутствует.
- Конфигурация общая для Android/iOS/Web; новых платформенных проверок нет. Принят контракт, обновлены окружения/команды, архитектура/матрица/аудит/дорожная карта и точка продолжения.
- Web +9 собран локально с текущими источниками меню/фото. version.json остаётся metadata-only: {version: 0.1.0, build: 9}. Policy в серверный файл не добавлена; deploy/rollback ещё не адаптированы для policy. Сервер, Caddy, Zak и 1С не менялись; Git-коммит не выполнялся.
