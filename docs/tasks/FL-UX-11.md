## Что сделано

PriceText сначала выводит текущую цену, затем исходную с новой строки при скидке. Серый цвет, зачёркивание и размер 80% сохранены. Без скидки остаётся одна цена. Применяется к карточкам меню, полному составу и суммам истории заказов; корзина использует отдельную строку расчёта.
