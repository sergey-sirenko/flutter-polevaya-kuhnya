## Что сделано

Сверены настройки test и Android. Release Android пока использует debug signing и временный applicationId.

Первая Web-компиляция выявила ошибку в [distribution.dart](../../lib/core/platform/distribution.dart): `PathUrlStrategy(null, true)` принимался native-заглушкой SDK, но Web требует ненулевой PlatformLocation. Передан `BrowserPlatformLocation()`; сохранение fragment оставлено. Финальная release Web-сборка успешна.

Первая Android-сборка упала в Kotlin incremental cache трёх плагинов: `this and base files have different roots` для Pub cache на C: и проекта на E:. В [gradle.properties](../../android/gradle.properties) отключена инкрементальная компиляция Kotlin. В [release-манифест](../../android/app/src/main/AndroidManifest.xml) добавлено INTERNET.

Для iOS добавлен корневой [codemagic.yaml](../../codemagic.yaml): workflow `ios-simulator-test` (Flutter 3.47.1, `mac_mini_m2`, analyze/test + `flutter build ios --debug --simulator` с test `--dart-define`, артефакт `Runner.app`). Создан отдельный GitHub-репозиторий [flutter-polevaya-kuhnya](https://github.com/sergey-sirenko/flutter-polevaya-kuhnya) (не сайт `polevaya-kuhnya`); `master` запушен по SSH. Пользователь подключил Codemagic CI/CD к репозиторию.
