# FL-UX-32 — Android без предупреждения при недоступной проверке версии

## Назначение
Открывать приложение для обычных Android-тестировщиков без ручного продолжения и технического баннера при ошибке проверки версии.

## Входные условия и оценка
Снимки пользователя; стандартный Android release использует prod URL https://new.obedmoscow.ru/version.json. При HTTP-проверке 02.10.2026 хост не разрешается. Конфигурация установленного APK неизвестна. Сложность 2/10, трудоёмкость низкая, LLM лёгкая; локальная правка UI. Тесты/превью не запускать по действующему ограничению; APK подписывает пользователь.

## План и критерии
- Автоматически продолжать Android при завершённой ошибке проверки.
- Не показывать Android-баннер unknown.
- Сохранить required и available, Web/iOS и исходное состояние ошибки.
- Analyze, diff-check; обновить состояние и номер.

## Состояние
Начата 02.10.2026; локальная реализация и проверка выполняются. Публикации нет.
