## Что сделано
BootLoading задаёт белый экран с индикатором 28 px для штатной проверки версии и ожидания меню главной. HTML использует соответствующий индикатор, удаляемый по flutter-first-frame; наличие события подтверждено в исходниках установленного Flutter engine. Noscript сохраняет контакты и скрывает индикатор.

Главная строится после результата menuControllerProvider; ошибка не скрывает статическое содержимое и даёт явный повтор. В hero удалён временный логотип; размеры фотографии определяются прежним AspectRatio 4/3. Загрузка/повторы изображений сохраняют существующие размеры и нулевые fade durations. Проверки обязательного обновления/ошибок версии, сессия, источники данных, навигация и API не менялись.
