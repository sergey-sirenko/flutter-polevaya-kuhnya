# FL-04-01 — Создать модели меню

## Назначение

- Бизнес-цель: типизированные недели, дни, категории, блюда, цены и ссылки на изображения для меню.
- Требования ТЗ: FR-M1–M3 в части данных; этап 4 [дорожной карты](<../../Дорожная карта.md>).
- Модуль: `lib/features/menu/menu_models.dart`.
- Ответственный: агент.

## Входные условия

- Зависимости: [FL-01-17](FL-01-17.md), [аудит полей FL-00-10](FL-00-10.md), [архитектура](../../ARCHITECTURE.md), разделы 2–3.
- Окружение: локальный Flutter/Dart, синтетические данные.
- Ограничения: живой файл меню не подтверждён; iOS-тестирование отложено. Серверные изменения и публикация не требуются.

## Оценка перед выполнением

- Вся подзадача: сложность 4/10; трудоёмкость средняя, ≈6% полного этапа 4; LLM средняя.
- Основание: расширение готовых моделей по статически подтверждённым именам полей, неизменяемость коллекций и регрессионные проверки. Внешнее ожидание фактического меню не входит в трудозатраты.

## Контракт моделей v0.1 (локальный объём)

Это контракт представления Flutter на основе FL-00-10, а не утверждение о проверенной серверной схеме. Существующие обязательные поля сохраняются: `weekType/days`, `date/categories`, `categoryId/categoryName/dishes`, `dishId/dishName/price`. Цена остаётся `num`, дата — `DateTime`, идентификаторы — непрозрачные строки. Доступность заказа из `menudates` определяется отдельно в FL-04-04.

Изображения: `MenuDish.imagePath` соответствует JSON `imagePath`, `MenuCategory.categoryImagePath` — JSON `categoryimagePath` (регистр сохранён). Тип `String?`; отсутствие/null/пустая строка означают отсутствие изображения. Неверный тип вызывает `FormatException`. Сохраняется имя ресурса из источника; модель не строит URL, не дописывает расширение, не загружает файл и не содержит токен. Правила URL, заглушки и загрузки — FL-04-09.

Вложенные списки копируются в неизменяемые коллекции при создании каждой модели. Изменение входного списка или попытка изменить список модели не должны менять снимок меню.

Полная политика необязательных/повреждённых JSON-полей — FL-04-02. Сортировка, нормализация недель и проверка календарных дат не добавляются здесь. Вес и состав остаются открытыми по FL-00-10: тип/единицы веса и источник описания требуют уточнения до карточки блюда FL-04-08; обязательность и единицы не выдумываются.

## Что сделано

Сверены существующие модели и статическая карта источника; определён локальный контракт v0.1. В [menu_models.dart](../../lib/features/menu/menu_models.dart) добавлены необязательные изображения блюда/категории и копирование списков через `List.unmodifiable` на каждом уровне.
