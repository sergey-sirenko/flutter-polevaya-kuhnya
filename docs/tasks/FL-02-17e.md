# FL-02-17e — Реализовать согласованную политику CORS

## Назначение

- Бизнес-цель: сузить CORS API Obmen с `*` до allowlist по [cors-policy.md](../../../Zak/docs/cors-policy.md), сохранив доступ текущего рабочего сайта (`www` и apex) без правок сайта/PWA.
- Требования ТЗ: API-10; §5.2 дорожной карты; политика FL-02-17d.
- Модуль: Zak BSL `ОбменHTTP`, HTTP-сервис `Obmen`; указатели Flutter.
- Ответственный: агент.

## Входные условия

- Зависимые: FL-02-17d; O-01/O-02 закрыты пользователем 27.09.2026.
- Нужные контракты: cors-policy v1.0.1.
- Окружение: исходники Zak; ИБ не обновлять в этой подзадаче.
- Ограничения: только BSL Zak по политике; **не менять** `polevaya-kuhnya` / Caddy / Flutter-код; browser CORS — FL-02-17f; без публикации.

## Оценка перед выполнением

- Объём: вся e. Сложность 7/10; трудоёмкость средняя ≈2% этапа 2; LLM сложная.
- Основание: общая точка CORS на границе HTTP, preflight, сохранение www/apex/test/flutter-test.

## План

- [x] Allowlist и отражение Origin в `УстановитьCORSЗаголовки`; убрать `*` и ACAC.
- [x] `ОтветСCORS` / `ОтветPreflightCORS`; обёртка User/Orders POST|GET|OPTIONS.
- [x] Убрать внутренние вызовы CORS без `Запрос` (ОтветУспех/Ошибка/корзина/регистрация).
- [x] Статическая сверка allowlist и отсутствие `*`+credentials; сайт не тронут.
- [x] Карточка, политика, PROJECT_STATE; остановка до загрузки ИБ / 17f.

## Критерии завершения

В исходниках Zak: ACAO только для Origin из §4.1 (включая `www`); без ACAC; OPTIONS через preflight с Max-Age; CORS на успехах/ошибках User/Orders через границу Obmen; код сайта не менялся. Загрузка ИБ и browser — не входят.

## Что сделано

В [ОбменHTTP](../../../Zak/Konf/CommonModules/ОбменHTTP/Ext/Module.bsl): `OriginИзЗапроса`, `КаноническийРазрешённыйOrigin` (4 host), `УстановитьCORSЗаголовки(Ответ, Запрос)`, `ОтветСCORS`, `ОтветPreflightCORS` (403 без allowlist / чужой метод; Max-Age 86400). Внутренние ответы без CORS; граница — Obmen.

В [Obmen](../../../Zak/Konf/HTTPServices/Obmen/Ext/Module.bsl): `ЗапросUserPOST/GET` и `ЗапросOrdersPOST` → `ОтветСCORS`; OPTIONS → `ОтветPreflightCORS`. SBP (HTML/callback) без CORS-обёртки — не браузерный API-клиент сайта.

В [ДоступСотрудниковКлиентов](../../../Zak/Konf/DataProcessors/ДоступСотрудниковКлиентов/Ext/ObjectModule.bsl): убран прямой CORS из `ОтветРегистрации` (ставит Obmen).

`polevaya-kuhnya` и Caddy не изменялись: рабочий сайт продолжает ходить на API с Origin `https://www.obedmoscow.ru` / apex из allowlist.

Позднее (тот же день): O-05 закрыт — `https://new.obedmoscow.ru` добавлен в политику v1.0.3 и в `КаноническийРазрешённыйOrigin`. DNS/Caddy `new` не настраивались.
