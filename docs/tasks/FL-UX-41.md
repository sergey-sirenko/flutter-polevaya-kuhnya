# FL-UX-41 — Автовосстановление без мелькающих сообщений

## Назначение
По поручению пользователя убрать мелькание «Есть сохранённый набор», «Восстановление корзины» и «Проверяем вход» при открытии сайта/F5 и автоматическом восстановлении.

## Входные условия и оценка
Общий UI Web/Android/iOS, текущая +80. Вся подзадача: сложность 2/10, трудоёмкость низкая, LLM лёгкая; презентация состояний загрузки. Отдельный UX-пакет вне этапа. Проверки сессии/заказов и сообщения реальных ошибок сохраняются. Тесты/превью не запускать по действующему ограничению.

## План и критерии
- Нейтральный индикатор вместо промежуточных текстов и временных кнопок личных страниц.
- Убрать текст восстановления из общего баннера и текст найденного набора.
- Сохранить обработку ошибки/ручной повтор и автоматическое восстановление.
- Analyze/diff-check/version-policy/Web-сборка; обновить состояние.
