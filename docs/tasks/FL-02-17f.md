## Что сделано

### CORS (политика v1.0.3 на живом API)

OPTIONS `V1/User/login`: отражение Origin, без ACAC, `Vary: Origin`, `Max-Age: 86400` для apex/www/test/flutter-test/new; evil и localhost → 403 без ACAO.

### Ошибки API-9

| Код | HTTP | CORS |
|---|---|---|
| `invalid_session` (плохой token) | 401 | да |
| `invalid_request` (нет deviceId) | 400 | да |
| `invalid_credentials` (фейк login) | 400 | да (после hotfix) |

### Browser

- `https://flutter-test.obedmoscow.ru`: OPTIONS + POST token/password-error — тело JSON читаемо.
- `https://obedmoscow.ru` (старый сайт): OPTIONS + POST token — читаемо.
- `https://new.obedmoscow.ru`: DNS отсутствует → browser M3a не выполнялся (HTTP OPTIONS с Origin `new` уже 200).

### Hotfix

`ШаблонUserLogin`: `ЗапросПользователя` вместо перезаписи HTTP-параметра; защита типа в `OriginИзЗапроса`. После загрузки в ИБ парольный отказ больше не даёт 500.

Для FL-02-19: CORS allowlist и 401/400 коды на login подтверждены; парольный путь после hotfix работоспособен; browser на `new` — после DNS/Caddy.
