## Восстановление

1. На новом компьютере перенести оба `.p12` из резервной папки в защищённую папку пользователя. Перед использованием ограничить доступ к папке владельцем, SYSTEM и администраторами.
2. Получить пароли из личного менеджера паролей. Не передавать их в чат, репозиторий или аргументы командной строки.
3. Проверить каждый файл командой `keytool -list -v -keystore <путь к p12> -storetype PKCS12 -alias <alias>`; `keytool` запросит пароль интерактивно. Сверить SHA-256 сертификата с указанными выше значениями.
4. Для прямого APK использовать **app signing**; для загрузки AAB — **upload**. При настройке Google Play и RuStore передавать собственный app signing key только их штатным защищённым способом. После первой настройки сверить сертификат APK, доставляемого каждым каналом, с app signing fingerprint.
