# Матрица требований ТЗ → задачи → проверки

**Дата:** 26.09.2026. **Основание:** [ТЗ 1.0](<../Техническое задание.md>), [дорожная карта 2.1](<../Дорожная карта.md>). Задача подготовки матрицы — FL-00-03.

**Актуализация 27.09.2026:** FR-A3 исключено решением пользователя; API-2 сохраняет регистрацию и смену email. Историческая дата первоначальной матрицы сохранена.

О — обязательное; Ж — желательное. Для API без явной отметки приоритет определяется обслуживаемым обязательным сценарием. API-7 сохраняет отметку ТЗ и отдельно указывает обязательность результата BL-2. Противоречие не считается решённым.

Матрица описывает **план проверок**. Все доказательства реализации приложения пока отсутствуют. После проверки в последней колонке добавляется ссылка на карточку, раздел результата, дату и версию. Завершение FL-00-03 означает полноту сопоставления, а не готовность функций.

ID задач без карточек пока являются обычным текстом: карточки создаются при начале работы. Их определения находятся в дорожной карте.

Документальная проверка покрытия после аудита — [FL-00-17](tasks/FL-00-17.md). Указатель существующих API-описаний и пробелов — [api-1c.md](api-1c.md). Эти документы не являются доказательством реализации или утверждением открытых контрактов.
