# FL-DESIGN-02 — «Белая кухня» в Flutter

01.10.2026. [План и карточка](../../tasks/FL-DESIGN-02.md). Вариант 1 принят пользователем, оформление перенесено в общий Flutter UI.

## Результат

- Белые поверхности, зелёные действия/цены #305F3D, светлые зелёные подложки #F0F5EF, границы #DCE5DD, радиус 12 px. Золотистый #ECAF3F — вторичный акцент преимуществ. Формы, профиль, корзина, календарь, сообщения и навигация используют общую тему.
- Категории 224 px, правая панель 400 px. Каталог: две карточки на 1200, три на 1440. До 1200 остаётся адаптивная оболочка; при 320 одна колонка, на 390 две. Крупный текст сокращает колонки, нижняя навигация телефона становится двухрядной.
- Фото блюда/категории/полного состава — целиком, contain, поверхность #FFFFFF. Цветных фильтров и обработки изображений нет. На главной фото/название/исходная цена реального блюда выбранного дня; до выбора берётся ближайший день меню, при отсутствии данных — логотип. Прежняя иллюстрация не используется главной.
- На телефоне категории доступны горизонтально, первое название раздела не дублируется в списке блюд. Пищевая ценность переносится без FittedBox; вспомогательные шрифты от 14 px, включая зачёркнутую цену. Граница выбранной карточки не меняет её геометрию.
- Web bootstrap, theme-color и PWA manifest согласованы с темой. Нативные ресурсы логотипа уже соответствуют #305F3D, iOS launch background белый; дополнительных нативных изменений не потребовалось.

Контроллеры/репозитории, API/1С, цены/скидки, доступность, revisions/pending, snapshot и отправка заказа не изменены. В гостевом просмотре выбор количества закрыт прежними проверками. Серверная сумма остаётся серверной; 355 ₽ в синтетическом превью — предварительные 2 × 110 + 135.
