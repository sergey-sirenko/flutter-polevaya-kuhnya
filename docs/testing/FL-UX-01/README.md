## Что работает в проверенном объёме

Регистрация тестового устройства и последующий вход завершились. Нижняя панель категорий прокручивается до последней категории, длинные названия переносятся. Начало доступного дня открывает категории, выбор супа увеличивает количество до 1 и итог до 110 ₽. Общая смена размера экрана не вызвала видимой ошибки Flutter. На широком экране каталог и календарь доступны одновременно.
